# NexusIDE — Releases

Artefatos oficiais do NexusIDE (DMG + ZIP do updater), assinados com
Developer ID e notarizados pela Apple. O código-fonte vive em repositório
privado; este espelho existe para distribuição e atualização automática.

Instalação: baixe o `.dmg` mais recente em Releases e arraste para
Applications. O app se atualiza sozinho a partir daqui.
