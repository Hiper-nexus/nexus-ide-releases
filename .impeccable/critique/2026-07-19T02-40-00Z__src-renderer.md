## O que mudou nesta passada (verificado em runtime)

- **Fundação**: Inter + JetBrains Mono bundled (mesmo render mac/win/linux);
  acento `#45d7ff` → `#3dd9ff` (AA ≥10:1 mantido, cursor do xterm casado);
  `lib/platform.ts` + `formatShortcut` — 56 ⌘ hardcoded viraram labels por OS;
  10 aria-labels em botões icon-only; hex `#22c55e`/`#ffd166` tokenizados;
  font-sizes em escala nos 3 CSS mexidos.
- **Chrome**: bar sem "Novo workspace" inline (menu ▾ da marca); frota fala
  "trabalhando/pronto/dormindo/morto" (nunca "zzz"/"x"); squads falam
  "orquestrador + N agentes" (nunca "orq + N workers").
- **Leigo**: Onboarding nunca abre com primário disabled — instala a CLI com
  confirmação nativa ou expande o guia de instalação; erro inline com saída.
- **DESIGN.md** criado (62 tokens declarados) e `design-system-sensor.mjs`
  corrigido (globToRegex single-pass — nunca casou `**/*.css`; regex de
  custom-property exigindo 2+ chars). Sensor: `ok: true`, 75 style files.

## Issues restantes

1. **[P1] Densidade da bar em full** — 13 controles em 1600px. Aceitável para
   cockpit; candidato: colapsar QuotaChip+CostSummary num único chip "Conta".
2. **[P1] Fallbacks defasados de var()** — `var(--accent, #45d7ff)` e outros
   espalhados (~20 arquivos): inertes hoje, mentem se o token sumir. Sweep
   próprio, arquivo a arquivo (relatório do agente CSS em 2026-07-19).
3. **[P2] Verdes/vermelhos não-token** (`#3dd68c` ×11, `#4ade80`, `#f87171` em
   product-wave/git-scm/launch-wizard) — próximos de `--live`/`--danger`,
   decisão de cor real por superfície.
4. **[P2] Undo inexistente** — fechar pane/missão é permanente; toast com
   desfazer seria o próximo salto de confiança para leigo.
5. **[P2] Voice HUD sobre conteúdo** — overlay grande; dock/recolher quando
   ocioso melhoraria a leitura do grid (é arrastável, mas o default cobre).
