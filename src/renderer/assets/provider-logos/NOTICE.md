# Provider logo assets

The provider marks in this directory are shown only to identify the corresponding
third-party CLI/service inside NexusIDE. All trademarks remain the property of
their respective owners.

- `claude.svg`, `codex.svg`, `kimi.svg`, `grok.svg`, `glm.svg`, `longcat.svg`,
  `agy.svg`, and `opencode.svg` were sourced from
  `@lobehub/icons-static-svg` 1.91.0 (MIT), without changing their geometry.
- `aider.png` is the public avatar of the official `Aider-AI` GitHub organization.

The application keeps these assets local so the settings UI works offline and
does not contact provider domains merely to render an icon.
