# Provider logo assets

The provider marks in this directory are shown only to identify the corresponding
third-party CLI/service inside NexusIDE. All trademarks remain the property of
their respective owners.

- `claude.svg`, `codex.svg`, `kimi.svg`, `grok.svg`, `glm.svg`, `longcat.svg`,
  `agy.svg`, and `opencode.svg` were sourced from
  `@lobehub/icons-static-svg` 1.91.0 (MIT), without changing their geometry.
- `aider.png` is the public avatar of the official `Aider-AI` GitHub organization.
- `qwen.svg`, `gemini.svg`, `deepseek.svg`, `sakana.svg`, `qoder.svg`, `omp.svg`,
  `muse.svg`, `prime-agent.svg`, `cursor-agent.svg`, `openclaude.svg`, and
  `devin.svg` are
  **original geometric identifiers drawn for NexusIDE**, not vendor artwork:
  they reproduce no part of any official logo and exist only so each CLI tile
  has a stable, distinguishable mark instead of a generic letter. Each one
  borrows only the vendor's signature accent colour. The vendors' trademarks
  and their own logos remain the property of their respective owners, and these
  drawings imply no affiliation with or endorsement by them.

The application keeps these assets local so the settings UI works offline and
does not contact provider domains merely to render an icon.

- `google-color.svg`, `replicate.svg`, and `elevenlabs.svg` were sourced from
  `@lobehub/icons-static-svg` 1.91.0 (MIT), without geometry changes.

- `groq.svg` and `gemini-color.svg` were sourced from
  `@lobehub/icons-static-svg` 1.91.0 (MIT). Gemini now uses this vendor mark;
  the old `gemini.svg` remains an unused original identifier.

- `deepseek-color.svg`, `qwen-color.svg`, `qoder-color.svg`, and `cursor.svg`
  are vendor marks from `@lobehub/icons-static-svg` 1.91.0 (MIT), replacing
  original identifiers for those services in ProviderLogo.

- `minimax-code.svg` is `minimax-color.svg` from `@lobehub/icons-static-svg`
  1.91.0 (MIT), without geometry changes. It identifies MiniMax Code and the
  MiniMax upstream; the mark remains MiniMax's trademark.

- `mimo-code.png` reuses the unchanged Xiaomi MiMo identifier already bundled
  at `src/shared/agent-icons/mimo-code.png`. It is used only to identify the
  corresponding official CLI/service; the mark remains Xiaomi's trademark.
