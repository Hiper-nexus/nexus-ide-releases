# C6: bounded file mode in the existing private channel

**Prerequisite measured.** Actual Muse 1.4.0-R4302.1 `muse.bash`, default Managed sandbox/proxy-only network, can write/read a new regular fixture file inside the Main-created channel directory under its existing private TMPDIR, outside workspace. No Unix permission was requested. Control50070:1 PASS/1 filtered case,5.91s; own file removed before channel disposal. The same SDK baseline denies outside-workspace writes. Direct TCP and default Unix requests fail with curl7; declaring `unix_socket_paths` asks a separate human network approval, and its internal request does not reach even an unfiltered PermissionRequest hook. Root independently measured Codex workspace-write with its existing TMPDIR read/write permission.

**Paths and ownership.** Extend `createNativeHeavyLocalChannel` and the SAME fixed `resources/heavy-command/local-channel.cjs` UtilityProcess entry with a Main-only `transport: 'file'` option/result property. Main still creates one private canonical directory per exact gate context, chmod700, before provider post. Keep the four existing env values in memory/env only. A small signed public transport manifest in that directory binds mode, directory and epoch to the existing Main Ed25519 key; the requester verifies it before selecting file mode. There is no automatic fallback after a denied network operation. Node22 fork remains an explicit test port only.

**Finite protocol.** Use16 fixed request slots and16 matching response names, no arbitrary paths, discovery bus or lock files. Client publishes a <=2KiB existing `{id,issuedAt,body,mac}` request with O_CREAT|O_EXCL|O_NOFOLLOW; exclusive publication chooses a free slot without overwriting another caller. It retains dev/ino for its own cleanup. Helper opens O_NONBLOCK|O_NOFOLLOW, requires a regular file with nlink1, caps size before reading and verifies stable FD identity. Incomplete/invalid frames never reach admission. A bounded periodic scan checks only the16 exact names, counting every occupied slot before parsing. Replies are <=2KiB, exclusively created on a fresh matching response path, and use the existing correlated Main-signed schema/hash/id/epoch. Client verifies the signature and exact request before returning a lease; it removes response first, then its own request, only after identity checks. No bearer/account token, request key or private signing key is written to disk or arguments.

**Authority stays in Main.** Reuse the current HMAC/replay/current/epoch checks and exact captured context, then call the SAME `NativeHeavyCommands.admit(ctx,body,signal)`. Files never supply role/scope or release a permit. Existing Host signature/live-image/uniqueID A+B observation is installed before grant; original target stays in the SDK sandbox with original cwd/env/stdio. Socket/file mode is a private lifecycle choice, not model input. Codex config stores only inherited env names; its original offline policy can remain unchanged in file mode. Muse's private resource-only PreToolUse transforms the original command without altering a permission decision; it needs no hook-env bearer.

**Cancel, drain and cleanup.** If a pending request disappears/changes identity, helper sends cancellation for its exact UUID; Main aborts and awaits that admission promise. Apply the existing360s request deadline and parent/context abort. After a reply is delivered, removal is transport completion, never physical release. SIGKILL is covered by Main's authenticated physical claim/owner observation plus deadline, not file disappearance. Dispose stops admission, waits own pending promises and exact native context/cohort drain, then exits the owned byte helper and observes actual exit. Main removes only recorded request/reply/manifest identities and rmdir only if empty. A foreign replacement remains untouched, makes cleanup fail explicitly and stays registered for retry. Failure paths retain ownership/proof until these stages finish.

**Required acceptance.** Actual Muse and Codex baseline/scheduled pairs with unchanged offline network and outside-write/direct-TCP/foreign-Unix denial; strong fresh A+B plus nested borrow and one grant→whole-cohort release; parallel slot publication, malformed/oversize/symlink/hardlink/replacement, replay/epoch, cancellation/late grant, helper death and pending/dispose identity-retry controls. Freeze the transport separately before private adapter wiring. This document proposes a bounded delta; it is not a C6 completion claim.
