# F-553 — Bootstrap do npm fixado usa executáveis POSIX no Windows

## F-553 | categoria: funcional | severidade: alta | status: corrigido

- Tela/fluxo: bootstrap do npm fixado dentro de `release:security` no Windows.
- Arquivo:linha: `scripts/make-release.mjs` (o bootstrap chamava `npm` e
  `/usr/bin/tar` diretamente, ambos incompatíveis com o host Windows).
- Passos: 1) preservar `Path` no ambiente; 2) executar o gate de segurança;
  3) o bootstrap chama o npm fixado.
- Esperado: Windows usa `npm.cmd` via o shell controlado e `tar` do sistema;
  macOS continua com `npm` e `/usr/bin/tar`.
- Observado: `spawnSync('npm')` retornou `ENOENT`, `npm.cmd` sem shell retornou
  `EINVAL` e `/usr/bin/tar` também retornou `ENOENT` no host Windows.
- Evidência: reprodução local em 2026-09-16 com `spawnSync`; `tar --version`
  confirmou o `C:\\Windows\\System32\\tar.exe` disponível.
- (resolvedor) Correcao: `bootstrapPinnedNpm` seleciona `npm.cmd` e `tar`
  somente no Windows; o executor reconhece o shim `.cmd` e usa o shell
  controlado para ele. O caminho macOS continua `npm` + `/usr/bin/tar`.
  Arquivos: `scripts/make-release.mjs`, `scripts/release-security-gate.mjs`
  e testes; commit `3cdefbd7`. Validado com `npx vitest run
  scripts/make-release.test.mjs scripts/release-security-gate.test.mjs`.
