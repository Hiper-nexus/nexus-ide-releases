# F-015 — OpenClaude logado no Keychain tratado como desconectado

## F-015 | categoria: funcional | severidade: alta | status: corrigido
- Tela/fluxo: Providers, escolha de CLI e alertas de login do OpenClaude.
- Arquivos: `src/main/adapters/native-oauth-keychain.ts`, `src/main/adapters/subscription-auth.ts`, `src/main/adapters/auth-probe.ts`.
- Passos: autenticar OpenClaude no macOS sem arquivo `.openclaude/.credentials.json`; consultar Providers.
- Esperado: reconhecer a credencial nativa independente do Claude.
- Observado: o detector só consultava o arquivo; a CLI instalada usa o serviço `OpenClaude-credentials` no Keychain, com hash do diretório quando o config home é personalizado.
- Evidência: inspeção do código instalado de OpenClaude e consulta somente leitura `openclaude auth status --json` com `loggedIn=true`, `authMethod=claude.ai`. A nova sonda assíncrona retornou OAuth utilizável no Keychain real. Teste RED do endpoint retornava missing para essa prova.
- Correção: consulta ao serviço próprio, isolamento por config home, payload OAuth utilizável obrigatório, snapshot não bloqueante e atualização explícita após login/logout. Nenhuma credencial foi copiada entre CLIs.
- Validação: typecheck, 101 testes focados de autenticação/configuração/Attention e `security:renderer-sinks` sem sinks executáveis. Fonte corrigida; sem commit ou atualização do app empacotado nesta tarefa.
