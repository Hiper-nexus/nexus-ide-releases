# F-633 — CLIs instaladas não eram atualizadas automaticamente

## F-633 | categoria: funcional | severidade: media | status: corrigido
- Tela/fluxo: Ajustes → Contas de IA → CLIs; abertura de panes no macOS/Windows.
- Arquivo:linha: `src/main/persistence/provider-config-store.ts:2114` (o único updater era o clique manual em `installCli`).
- Passos: 1) Instalar uma CLI reconhecida. 2) Manter o Nexus aberto depois de uma nova versão do provider. 3) Abrir um pane.
- Esperado: após consentimento do operador, Nexus atualiza a instalação efetiva quando não há pane vivo daquela CLI e passa a usar a versão verificada.
- Observado: não havia agendamento, consentimento nem verificação de atualização em background; o pane continuava na versão instalada até clicar manualmente.
- Evidencia: `rg -n 'installCli|startCliAutoUpdate' src/main/main.ts src/main/persistence/provider-config-store.ts` antes do fix só encontrava o handler manual.
- (resolvedor) Correcao: o Main pede consentimento nativo, mostra os comandos elegíveis e registra a escolha. A recusa inicial adia a pergunta por sete dias; o controle em CLIs permite desligar indefinidamente ou reativar mediante nova confirmação nativa. A fila serial tenta uma CLI por minuto, com limite de uma verificação bem-sucedida por dia por adapter e uma hora de espera após erro. Só executa receitas argv de instalações reconhecidas e graváveis; scripts, WinGet, casks, overrides e caminhos não reconhecidos continuam manuais. Revalida o launcher usado pelo pane, ignora adapters com pane vivo, coordena a instalação de primeiro uso, o botão manual e o spawn por uma trava comum, reexamina o PATH e confirma versão e identidade do executável depois do update. Se a versão não mudar, registra apenas “checked”. Arquivos: `src/main/adapters/cli-auto-update.ts`, `src/main/persistence/provider-config-store.ts`, `src/main/main.ts`, `src/shared/provider-settings-types.ts`, `src/shared/types.ts`, `src/preload/preload.ts`, `src/renderer/components/settings/ProvidersPanel.tsx` e testes co-localizados. Validação: cinco suítes focadas (126 testes), `npm run security:renderer-sinks`; typecheck final pendente do gate unificado de release.
