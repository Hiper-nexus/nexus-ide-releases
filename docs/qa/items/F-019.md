# F-019 — Cota de uma conta substituída pela sessão global

## F-019 | categoria: funcional | severidade: alta | status: corrigido
- Fluxo: Uso e cotas › múltiplas contas salvas.
- Arquivos: `src/main/quota/provider-usage-auth.ts`, `src/main/quota/provider-live-usage.ts`.
- Esperado: credenciais e cota da conta exata, ou resultado desconhecido.
- Observado: após falha/ausência de uma credencial pinada, os resolvers consultavam login nativo, chave global ou launcher. O resultado de outra conta podia aparecer na linha pinada. OpenCode também carregava todas as chaves nativas na consulta de uma conta salva.
- Evidência: regressões RED com contas fictícias, arquivo nativo sentinela e fetch simulado.
- Correção: validar o adapter da conta e encerrar a busca no seu próprio cofre; nenhuma fonte global/nativa é consultada para a linha pinada. OpenCode preserva essa mesma fronteira.
- Limite: cofre ainda não desbloqueado produz desconhecido; não é substituído pela conta global.
- Validação: 144 testes de quota/native auth isolados; typecheck e renderer sinks.
