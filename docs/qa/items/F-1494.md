# F-1494 — Caminho Expresso conferia só a ferramenta do coordenador

## F-1494 | categoria: funcional | severidade: alta | status: corrigido
- Renumerado na integração com a origin (0.76.252): este achado era o F-1440 da frente de squads (nunca publicado) e virou F-1494 para não colidir com a numeração que a origin publicou (F-1436..F-1451).
- Tela/fluxo: Início / Nova missão → Caminho Expresso → Iniciar criação (`startExpress`, `src/renderer/components/mission/MissionSetup.tsx`).
- Arquivo:linha: `src/renderer/components/mission/MissionSetup.tsx:950-957` (antes) — só o papel `orchestrator` passava por `issueForAgent`.
- Passos: 1) Criar equipe em Configurações › Equipes (o rascunho põe `codex` em todos os papéis, `src/renderer/components/settings/ModuleSections.tsx:306-341`) numa máquina sem o Codex e trocar só o coordenador para uma ferramenta instalada; ou usar uma equipe importada de outra máquina. 2) Usar integrantes e iniciar pelo Expresso.
- Esperado: antes de preparar a missão, o Expresso confere a ferramenta de todos os papéis e diz qual papel precisa de outra ferramenta e onde trocar.
- Observado: o Expresso preparava e iniciava a missão; ela falhava depois, ao abrir o terminal do executor/revisor. O Continuar da Equipe já recusava esse caso ("A ferramenta de “X” não está instalada nesta máquina."), o Expresso não.
- Causa raiz: `startExpress` só chamava `issueForAgent` para o coordenador; o prepare do Main não confere a prontidão dos workers (`requireProviderReadiness: false`).
- (resolvedor) Correcao: `startExpress` recusa, antes do prepare, qualquer papel cuja CLI não esteja entre as detectadas (`readiness.detectedAdapters`, a mesma régua de `missionRosterIssue`), com "A ferramenta de “<papel>” (<ferramenta>) não está instalada nesta máquina. Troque a ferramenta desse papel em Personalizar equipe." A conferência do coordenador (sessão, ferramenta desligada, F-1491) continua antes. Ferramenta só desligada num worker segue como dica no cartão, como na Equipe.

  - RED (código antigo): `npx vitest run src/renderer/components/mission/MissionSetup.test.tsx -t "F-1494"` → `expected "vi.fn()" to not be called at all, but actually been called 1 times` (o `mission.prepare` saía com executor/revisor no Codex não instalado).
  - GREEN: `npx vitest run src/renderer/components/mission/MissionSetup.test.tsx MissionSetup.home.test.tsx MissionSetup.pet.test.tsx MissionSetup.legacy-replacement.test.tsx` → 115/115 (inclui o teste que despacha o AGY escolhido pelo operador como worker).
