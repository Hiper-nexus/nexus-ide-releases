# F-353 — Pane reaberto duplica cada tecla enviada ao terminal

## F-353 | categoria: funcional | severidade: alta | status: corrigido

- Tela/fluxo: terminal que terminou e é reaberto como shell ao pressionar uma
  tecla.
- Arquivo:linha: `src/renderer/terminal/terminal-host.ts`
  (`reclaimExitedPaneAsShell`).
- Passos: 1) abrir um pane; 2) deixar o processo encerrar; 3) pressionar uma
  tecla para reabrir o shell; 4) digitar no novo prompt.
- Esperado: cada tecla é escrita uma vez no novo PTY.
- Observado: o listener de entrada da sessão encerrada continuava no xterm e a
  nova sessão criava outro listener; por isso uma tecla como `C` aparecia como
  `CC` ou mais vezes.
- Evidência: captura do operador em 2026-09-16 e teste de regressão que falhou
  com duas chamadas de `pty.write` antes da correção.
- (resolvedor) Correcao:
  - Causa raiz: a sessão encerrada preserva corretamente seu listener até a
    tecla de recuperação, mas `reclaimExitedPaneAsShell` iniciava a substituta
    sem descartar esse listener.
  - `terminal-host.ts` incrementa a geração e descarta as subscriptions antigas
    antes de criar o shell substituto; o teste em `terminal-host.test.ts` prova
    uma única escrita após a reabertura. Commit `aa975c2c`
    (`fix(renderer): F-353 — avoid duplicate pane keyboard input`).
  - Validação: `npx vitest run src/renderer/terminal/terminal-host.test.ts`,
    `npm run typecheck` e `npm run security:renderer-sinks` passaram.
