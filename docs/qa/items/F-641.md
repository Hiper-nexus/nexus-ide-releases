# F-641 — Skills de papel `oc-*` não embarcam no app e `nexus_skills install` sempre recusa

## F-641 | categoria: funcional | severidade: media | status: corrigido
- Tela/fluxo: skills de papel da 0.76.96 (`oc-pilot`, `oc-builder`, `oc-scout`, `oc-conveyor`) e a tool `nexus_skills install|remove`.
- Arquivo:linha: `src/main/orch/tools-skill-ops.ts:34` (fonte procurada em `process.resourcesPath/skills` e `__dirname/../../../resources/skills`), `forge.config.ts:328` (`resources/skills` fora do `extraResource`), `src/main/orch/skill-mirror.ts:232` (`BUNDLED_MANIFESTS` sem as `oc-*`).
- Passos: 1) App empacotado (Mac ou Windows) ou `npm start`. 2) `nexus_skills { op: 'install', name: 'oc-pilot' }`. 3) Abrir pane direto e procurar `oc-pilot` nas skills do CLI.
- Esperado: as quatro skills chegam com o app, o skill-mirror as espelha por CLI (o changelog da 0.76.96 promete isso) e o install copia a skill embarcada.
- Observado: `resources/skills/` não entra no pacote; o caminho `__dirname/../../../resources` só acerta dentro do vitest (no bundle `.vite/build` aponta para fora do projeto). O install responde "não embarca com o app" para toda skill — inclusive `impeccable`, `archify` e as demais de `BUNDLED_GUIDED_SKILLS`, que só existem como manifesto. O skill-mirror nunca materializou as `oc-*`, contrariando o contrato de `BUNDLED_GUIDED_SKILLS` ("ship with Nexus and can be materialized by skill-mirror"). O teste do install cobria só path traversal.
- Evidencia: `app-0.76.95/resources` e o `extraResource` do forge sem `skills`; `~/.nexus/generated-skills` sem nenhuma `oc-*`.
- (resolvedor) Correcao: as `oc-*` seguem a receita das skills embutidas — `assets/skills/` → `scripts/bundle-skills.mjs` → manifestos gerados → `BUNDLED_MANIFESTS`. `bundledSkillSourceDir(name)` devolve a skill materializada na raiz gerada do Main, e o `nexus_skills` copia dali. Testes: `skill-mirror.test.ts` — toda skill de `BUNDLED_GUIDED_SKILLS` existe no bundle materializado (falha no código antigo) e a `oc-pilot` sai do manifesto; `tools-skill-ops.test.ts` — o install copia da raiz gerada.
