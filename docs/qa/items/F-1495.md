# F-1495 — Editor de equipe aceitava nome de agente repetido ou com espaço nas pontas

## F-1495 | categoria: funcional | severidade: media | status: corrigido
- Renumerado na integração com a origin (0.76.252): este achado era o F-1441 da frente de squads (nunca publicado) e virou F-1495 para não colidir com a numeração que a origin publicou (F-1436..F-1451).
- Tela/fluxo: Configurações › Equipes › Criar/Editar equipe › nome do agente (`src/renderer/components/SquadEditor.tsx` → `applySquadEdit`, `src/shared/squad-edit.ts`).
- Arquivo:linha: `src/renderer/components/SquadEditor.tsx:211-216` (antes) — o campo gravava o texto cru; `src/shared/squad-edit.ts:37-43` (antes) — nenhuma conferência de nome de agente.
- Passos: 1) Dar o mesmo nome a dois agentes (ex.: "Executor" e "executor ") ou deixar espaço no fim de um nome. 2) Salvar e usar a equipe numa missão.
- Esperado: o editor recusa nome repetido (comparando sem espaços nas pontas e sem diferenciar maiúsculas) e salva o nome sem espaços nas pontas.
- Observado: salvava; no meio da missão o Maestro pedia o agente pelo nome e o Main respondia "unknown squad agent" (`src/main/orch/tools-panes.ts:1543-1548`), porque `findAgentInSquad` (`src/main/orch/squad-store.ts:731-741`) só aceita um casamento exato e único por nome.
- Causa raiz: o editor não validava nem normalizava `agentName`; a regra de unicidade só existe implicitamente no lookup do Main.
- (resolvedor) Correcao: `applySquadEdit` recusa nome vazio ("Dê um nome a cada agente da equipe.") e nome repetido — chave `trim()` + `toLocaleLowerCase('pt-BR')` — com "Dois agentes se chamam “<nome>”. Dê um nome diferente a cada agente."; o roster salvo leva `agentName.trim()`. O editor mostra a recusa no `role="alert"` e não chama `saveSquad`. O schema do Main fica com a frente do Main.
- Evidencia:
  - RED (código antigo): `npx vitest run src/renderer/components/SquadEditor.test.tsx src/shared/squad-edit.test.ts -t "F-1495"` → 3 falhas: `applySquadEdit` aceitava "Maestro" e "  maestro "; devolvia `[' Maestro ', 'Executor\t']`; o editor chamava `saveSquad` com o nome repetido.
  - GREEN: `npx vitest run src/renderer/components/SquadEditor.test.tsx src/shared/squad-edit.test.ts src/renderer/components/settings/SettingsSquads.capabilities.test.tsx` → 30/30. Nenhuma equipe interna (`src/main/orch/builtin-squads.ts`) repete nome de agente, então "Criar cópia" continua funcionando.
