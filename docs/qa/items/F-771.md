# F-771 — Roteamento ignorava capacidade: "busca na web" ia para CLI sem WebSearch

## F-771 | categoria: funcional | severidade: media | status: corrigido
- Tela/fluxo: roteamento de tasks (`routeTask`/`routeTaskForCaller`) para CLIs com e sem ferramenta de busca na web.
- Arquivo:linha: `src/main/orch/task-router.ts` (`AdapterAvailability`, `routeTask`), `src/shared/adapter-types.ts` (`cliPtyAdapterSchema.capabilities`), `src/main/orch/tools-domain.ts` (`buildAdapters`).
- Passos: 1) Tarefa que pede dado vivo — "faça uma busca na web sobre o estado da arte de X" ou "pesquise as versões atuais". 2) Pool com CLIs sem ferramenta de busca (muse, mimo-code, qwen…) à frente na tabela de custo. 3) Rotear.
- Esperado: o candidato escolhido tem busca na web declarada quando existe um instalado que a declara.
- Observado (evidência da missão, 02/10): duas pesquisas com busca na web foram para `muse` e `mimo-code` na rota free, e o MiMo respondeu "WebSearch indisponível neste pane". Não havia eixo de capacidade — todos os adapters eram tratados como intercambiáveis.
- Evidencia: `npx vitest run src/main/orch/task-router-capabilities.test.ts` — falha no HEAD (o arquivo nem importa: `taskNeedsWebSearch` e o filtro não existiam); 4/4 passando no código corrigido.
- (resolvedor) Correcao: a causa era a ausência de eixo de capacidade no contrato de roteamento. Adicionados: `AdapterRouteCapabilities` (`webSearch`, `readOnlyEnforceable`, `handoffMcp`, `maxContext`) em `AdapterAvailability`; campo `capabilities` no schema de manifest (`webSearch`, `maxContext` — distinto de `AdapterCapabilityMatrix`, que é qualificação de release); `capabilities.webSearch: true` só nos manifests com evidência de tool nativa (claude, agy, kimi, grok — demais CLIs ficaram sem a flag por falta de evidência no código/manifest/doc); `taskNeedsWebSearch()` (pt+en); filtro ANTES do ranking que trata candidato sem a flag como não-instalado quando algum instalado a declara, com nota no `reason`; fail-open quando nenhum declara. `routeTaskForCaller` popula o eixo a partir do manifest + `supportsEnforceableReadOnlyNativeAuthority` + `canUseNexusMcp`. Arquivos: `src/main/orch/task-router.ts`, `src/main/orch/task-router-capabilities.test.ts`, `src/shared/adapter-types.ts`, `src/main/orch/tools-domain.ts`, `src/adapters/builtin/{agy,claude,grok,kimi}.json`. Validação: vizinhos verdes + `npm run typecheck` limpo.
- Como foi achado: lacuna G3 da mesma auditoria + o relato real do MiMo ("WebSearch indisponível neste pane").
