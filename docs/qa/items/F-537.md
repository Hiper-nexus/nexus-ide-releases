# F-537 — Travamento de spawn no GLM, descarte de prompt no Devin e perda de entrada no Kimi e Antigravity

## F-537 | categoria: backend | severidade: alta | status: corrigido
- Tela/fluxo: Orquestração de Agentes CLI / Spawning e Injeção de Prompt Inicial (GLM, Devin, Kimi, AGY)
- Arquivo:linha: `src/adapters/builtin/glm.json:11`, `src/adapters/builtin/glm-flash.json:11`, `src/adapters/builtin/devin.json:10`, `src/main/orch/boot-prompt-watchdog.ts:32`, `src/shared/cli-initial-prompt.ts:24`, `src/main/orch/tool-util.ts:80`, `src/main/pty/pty-manager.ts:3600`
- Passos:
  1) Orquestrador spawna agentes GLM, Devin, Kimi ou Antigravity (AGY) atribuindo uma tarefa com prompt inicial.
  2) Observar comportamento durante o boot de cada modelo no terminal.
- Esperado:
  - GLM deve subir imediatamente aprovado para edição de arquivos no repositório.
  - Devin deve receber o prompt inicial na inicialização e começar o trabalho sem perder a mensagem.
  - Kimi e Antigravity (AGY) devem receber prompts multilinha formatados sem quebras por bracketed paste e sem ter o buffer limpo por timeout.
- Observado:
  - GLM falhava no spawn travado em diálogo interativo de confirmação de permissões de edição de arquivo e confirmação de diretório confiável.
  - Devin perdia o prompt de nascimento porque a injeção usava `paste` no xterm antes da interface TUI do Devin estar pronta.
  - Kimi e AGY (CLIs baseadas em Ink/React TUI) rejeitam sequências de controle `\x1b[200~` / `\x1b[201~` (bracketed paste) inserindo caracteres corrompidos, e o watchdog `clearStrandedComposer()` emitia `Ctrl+U` (`\x15`) incondicionalmente em caso de timeout de aceitação mesmo após o comando já ter sido submetido com Enter (`submitted === true`), apagando o prompt já enviado pelo orquestrador.
- Evidencia:
  - `glm.json` e `glm-flash.json`: adicionado `"extraArgs": ["--permission-mode", "acceptEdits"]` e regex de detecção de diálogo de pasta em `boot-prompt-watchdog.ts` expandida para casar com termos de diretório/repositório/workspace.
  - `devin.json`: alterado `initialPrompt` de `"paste"` para `"positional"`.
  - `cli-initial-prompt.ts`: adicionado `devin` à lista `POSITIONAL_BINARIES` com separador `-- <prompt>` conforme especificação da CLI oficial do Devin.
  - `tool-util.ts`: injeção de prompt respeita `allowsBracketedPaste: false` para Kimi, AGY e Devin, enviando raw newline; proteção adicionada em `clearStrandedComposer` (`if (!accepted && !submitted)`), garantindo que nada seja apagado se a submissão com Enter já ocorreu.
  - Testes validados em `src/shared/cli-initial-prompt.test.ts`, `src/main/orch/boot-prompt-watchdog.test.ts`, `src/main/pty/pty-manager.test.ts` (85 testes passando) e `npm run typecheck`.
- (resolvedor) Correcao:
  - `src/adapters/builtin/glm.json`, `src/adapters/builtin/glm-flash.json`, `src/adapters/builtin/devin.json`, `src/shared/adapter-types.ts`, `src/shared/cli-initial-prompt.ts`, `src/shared/cli-initial-prompt.test.ts`, `src/main/orch/boot-prompt-watchdog.ts`, `src/main/orch/tool-util.ts`, `src/main/pty/pty-manager.ts`.
