# F-552 — Gate de segurança perde o PATH no host Windows

## F-552 | categoria: funcional | severidade: alta | status: corrigido

- Tela/fluxo: `npm run release:security` antes da publicação Windows.
- Arquivo:linha: `scripts/release-security-gate.mjs` (allow-list do ambiente
  isolado tratava nome de variável de ambiente como sensível a maiúsculas).
- Passos: 1) executar o gate no Windows, onde o ambiente usa `Path`; 2) o gate
  inicializa o npm fixado; 3) o processo filho tenta executar `npm`.
- Esperado: o `Path` do Windows permanece no ambiente reduzido e o npm fixado
  é obtido com a mesma política de allow-list.
- Observado: o `Path` era removido porque só `PATH` era aceito; o gate falhava
  com `spawnSync npm ENOENT`.
- Evidência: reprodução local em 2026-09-16; `Object.keys(process.env)` expôs
  somente `Path` e `npm run release:security` retornou o erro citado.
- (resolvedor) Correcao: `releaseSecurityEnvironment` trata somente `Path`
  como equivalente a `PATH` quando a plataforma é Windows, preservando a
  allow-list e removendo segredos. Arquivos:
  `scripts/release-security-gate.mjs` e o teste co-localizado; commit
  `4a53fc71`. Validado com `npx vitest run
  scripts/release-security-gate.test.mjs` e `npm run typecheck`.
