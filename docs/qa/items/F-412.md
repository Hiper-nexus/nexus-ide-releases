# F-412 — fast-uri 3.1.7 e ip-address 10.5.1 fixados nos overrides com três alertas moderados bloqueavam o gate de release

## F-412 | categoria: seguranca | severidade: media | status: corrigido
- Tela/fluxo: gate `npm run release:security` (audit de produção e do toolchain precisam dar 0).
- Arquivo:linha: `package.json` `overrides` (`"fast-uri": "3.1.7"`, `"ip-address": "10.5.1"`).
- Passos: 1) `npm audit` no HEAD 920a626c (30/09).
- Esperado: 0 vulnerabilidades no audit de produção e no do toolchain.
- Observado: 4 moderadas, todas no toolchain de build: `fast-uri` ≤ 3.1.7 (GHSA-hrr3-gc8f-f4qj, normalização de host com octeto percent-encoded), via `ajv` e `schema-utils` do webpack/electron-forge; `ip-address` ≤ 10.7.0 (GHSA-j6r3-76f7-8jcv, `isInSubnet` compara famílias diferentes; GHSA-h3mg-xc3c-68pw, diagnóstico sem limite de tamanho), via `socks` e `@electron/node-gyp`. `npm audit --omit=dev` dava 0.
- Evidencia: `npm audit --json` de 30/09; `npm view fast-uri time` e `npm view ip-address time` (3.1.8 e 10.7.2 publicados em 2026-09-15).
- Relacionado: F-411.
- (resolvedor) Correcao: overrides para `fast-uri` 3.1.8 e `ip-address` 10.7.2, as duas publicadas há 15 dias. `npm install --package-lock-only --ignore-scripts` e depois `npm install --ignore-scripts`; o lockfile só mudou nos dois registros. `npm audit` e `npm audit --omit=dev` voltaram a 0.
