# F-1236 — Confirmação HTTP MCP presa a uma janela fora da vista segura a fila de confirmações

## F-1236 | categoria: funcional | severidade: baixa | status: precisa-decisao
- Tela/fluxo: confirmação de ferramenta pedida por agente via MCP HTTP (`showHttpMcpConfirmation`).
- Arquivo:linha: `src/main/orch/mcp-server.ts:351-372`.
- Origem: revisão cruzada da 0.76.236 (achado 3, PLAUSIBLE).
- Observado (por leitura): desde o F-1200 o diálogo abre como sheet numa janela viva, sem prazo. Se a janela está minimizada ou em outro Space, a pergunta fica aberta indefinidamente. Como o `McpConfirmationScheduler` mostra uma por vez, as confirmações HTTP de todas as sessões esperam atrás dela.
- Segurança: nada é aprovado por isso; continua fail-closed.
- Pergunta ao operador: um agente pedindo confirmação com o operador ausente deve esperar até ele voltar (hoje) ou ser negado depois de um prazo (como o ACP, 120 s)? Negar destrava a fila, mas faz o agente falhar enquanto o operador está fora.
