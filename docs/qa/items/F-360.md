# F-360 — Atualizar Claude modifica instalação npm, mas pane usa binário nativo antigo

## F-360 | categoria: funcional | severidade: media | status: corrigido
- Tela/fluxo: Ajustes → Contas de IA → CLIs → Claude → Atualizar CLI.
- Arquivo:linha: `src/main/persistence/provider-config-store.ts:1805`; `src/main/adapters/cli-install-recipes.ts:165`
- Passos: 1) Instalar Claude pelo instalador nativo e manter npm disponível. 2) Clicar Atualizar CLI duas vezes. 3) Abrir um pane Claude.
- Esperado: a atualização age sobre o mesmo executável que o pane vai abrir; o resultado informa a versão observada.
- Observado: a confirmação executa `npm install -g @anthropic-ai/claude-code` e anuncia sucesso, mas o pane continua em `2.1.278`.
- Evidencia: screenshots de 22/09/2026 fornecidas pelo operador; nesta máquina `~/.local/bin/claude` aponta para `~/.local/share/claude/versions/2.1.278` enquanto o pacote npm global está em `2.1.280`.
- Relacionado a F-598: aquele finding tratou a visibilidade do progresso, não a escolha da instalação atualizada.
- (resolvedor) Correcao: o updater escolhia a primeira receita cujo runner existia, mesmo quando o pane usava outra instalação. Agora seleciona o canal pelo executável efetivo (self-update nativo, WinGet, Homebrew do prefixo correto, npm no prefixo da instalação, uv no diretório do tool ou script oficial com diretório pinado), confirma o argv realmente usado e lê `--version` do binário do pane após reexaminar o PATH. Se o PATH passa a apontar para outro launcher, não atribui a mudança ao instalador. A UI distingue versão alterada, inalterada e apenas verificada; sem prova de versão não anuncia sucesso. O review fechou os casos de shim Windows que só mencionava o pacote em comentário, CLI nativa `.exe` dentro de pacote npm, WinGet com sufixo de origem e instalador AGY que fazia no-op sobre binário existente. Arquivos: `src/main/adapters/cli-install-recipes.ts`, `windows-npm-shim.ts`, `cli-update-observation.ts`, `src/main/persistence/provider-config-store.ts`, `src/renderer/components/settings/ProvidersPanel.tsx`, `providers-panel-view.ts`, `src/shared/types.ts` e testes co-localizados. Validação: 251 testes focados, `npm run typecheck`, `npm run security:renderer-sinks` e atualização real do launcher nativo Claude de `2.1.278` para `2.1.280`. Commit: o commit deste finding.
