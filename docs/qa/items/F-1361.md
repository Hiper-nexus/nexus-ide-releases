# F-1361 — `node -e` com require dinâmico rodava o compilador sem pedir admissão

## F-1361 | categoria: performance | severidade: media | status: corrigido
- Tela/fluxo: Bash de agente com o hook pesado (`resources/heavy-command/shell.bash`) → `classify.cjs` → `catalog.commandKind` → `programKind` (`node`) → `inlineKind`. O Main lê o mesmo catálogo em `heavy-command-classifier.ts`.
- Arquivo:linha (antes): `resources/heavy-command/catalog.cjs:488-497`. O `inlineKind` só olhava os nomes de módulo escritos como literal no código. `require(process.env.TS)` não tem literal, então voltava `null`. `programKind` propagava o `null`, e o `shell.bash` dispensava a reserva.
- Passos: `NODE_OPTIONS= node -e 'const ts=require(process.env.TS); ts.createProgram(["fixture.ts"],{noEmit:true}).getSemanticDiagnostics()'`, com `TS` apontando para o `typescript` e o endpoint de admissão sempre negando.
- Esperado: o comando pede admissão e, negado, sai com 78 sem rodar o compilador.
- Observado: exit 0, nenhum pedido de admissão, e o compilador rodou (`REAL_TSC_RAN 1`).
- Evidencia (RED, fonte anterior):
  - `heavy-command-catalog.test.ts`: 5 casos falharam (`require(process.env.TS)`, `import(process.env.MOD)`, template com `${…}`, `'type' + 'script'` e o argv direto `['node','-e','require(process.env.TS)…']`). Todos voltavam `null` em vez de `build`.
  - Ponta a ponta com o Bash real, o `shell.bash` do catálogo e um endpoint que nega tudo (reprodução da sonda G, adaptada): base `cb3191f3f` → `{"code":0,"requests":0,"stdout":"REAL_TSC_RAN 1\n"}`. Com a correção → `{"code":78,"requests":1,"stdout":""}`.
- Origem: sonda s240/G.
- (resolvedor) Correcao:
  - `inlineKind` troca cada literal por um marcador e procura `require(`/`import(` cujo argumento não seja um único literal simples. Template com `${…}` não conta como literal. Se acha, o código só nomeia o módulo em tempo de execução, e o resultado é `build`.
  - Inline comprovadamente leve continua livre: `require("fs")`, `require( 'fs' )`, `import('node:fs')`, `` require(`path`) ``, `console.log(1)` e `process.version` seguem `null`.
  - Arquivos: `resources/heavy-command/catalog.cjs`, `src/main/orch/heavy-command-catalog.test.ts`.
- Validacao:
  - `heavy-command-catalog.test.ts` + `heavy-command-classifier.test.ts`: 232/232.
  - Reprodução ponta a ponta acima: exit 78 com 1 pedido.
