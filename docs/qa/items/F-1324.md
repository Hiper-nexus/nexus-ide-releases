# F-1324 — hunk-tracker perdia o nome de arquivos com caminho entre aspas do Git

## F-1324 | categoria: corretude | severidade: media | status: corrigido
- Tela/fluxo: `nexus_hunks_analyze` / atribuição de hunks a agentes (`src/main/orch/hunk-tracker.ts` consome `parseUnifiedDiff`) — varredura s240, sonda A1.
- Arquivo:linha (antes, base cb3191f3f): `src/shared/hunk-tracker.ts:42` (regex `diff --git a/… b/…` só sem aspas), `:48-49` (`+++` não decodificava C-quoted nem tirava `b/` depois de decodificar; `/dev/null` deixava `file=''`).
- Passos: 1) Renomeie/edite um arquivo com nome não-ASCII (`café.ts`) e rode `git diff` — o Git emite `diff --git "a/caf\303\251.ts" "b/caf\303\251.ts"`. 2) `parseUnifiedDiff` devolve o hunk com `file='"b/caf\303\251.ts"'` (crú, com aspas e escapes). 3) Num diff de exclusão (`+++ /dev/null`), `file` volta `''` e a atribuição em `attributeHunks` (`:99-103`) não casa com caminho nenhum.
- Esperado: `parseUnifiedDiff(diff)[0].file === 'café.ts'` em modificação e exclusão entre aspas; escapes octais UTF-8, `\"`, `\\`, `\t`, `\n` decodificados em `diff --git`, `---` e `+++`.
- Observado: cabeçalho entre aspas não casava o regex (file ficou o token cru); na exclusão o `/dev/null` preservava o file anterior — que, sem o casamento do `diff --git`, era `''`.
- Evidencia: teste novo "F-1324: decodifica caminhos C-quoted do Git em modificação e exclusão" em `src/main/orch/hunk-tracker.test.ts` escrito ANTES da correção — vermelho com `expected '"b/caf\303\251.ts"' to be 'café.ts'`.
- (resolvedor) Correcao:
  - Causa raiz: o parser só conhecia a forma não citada dos três cabeçalhos e nunca decodificava escapes C; na exclusão não existia noção de nome antigo.
  - `decodeGitPathToken` decodifica token entre aspas (octais de byte UTF-8 agrupados e decodificados via `decodeURIComponent`, com fallback Latin-1; escapes `a b f n r t v \\ "`); `splitDiffGitPaths` separa os dois tokens do `diff --git` respeitando escapes dentro das aspas; `stripDiffPrefix` remove `a/`/`b/` DEPOIS de decodificar. O `---` passa a ser lido para `oldFile`, e `+++ /dev/null` usa o nome antigo. Token sem aspas volta byte a byte como antes.
  - Arquivos: `src/shared/hunk-tracker.ts`, `src/main/orch/hunk-tracker.test.ts`. Commit: ver `git log --grep F-1324`.
- Validacao: `npx vitest run src/main/orch/hunk-tracker.test.ts` — verde (inclui os 2 testes pré-existentes de parse/atribuição sem aspas, que garantem compatibilidade).
- Riscos: escape desconhecido (`\x`) decai para o caractere literal (o Git nunca emite); UTF-8 inválido nos octais cai no fallback Latin-1 em vez de quebrar o parse. Caminho não citado com espaço continua indivisível no `diff --git` — comportamento pré-existente (o Git cita esses caminhos).
