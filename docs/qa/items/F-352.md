# F-352 — Navegação de voz quebra quando o vínculo transitório de pane ainda não hidratou

## F-352 | categoria: funcional | severidade: alta | status: corrigido
- Tela/fluxo: comandos de voz que revelam um shell ou agente normal após a
  seleção de um pane.
- Arquivo:linha: `src/renderer/lib/mission-attention-route.ts:82`.
- Passos:
  1) Usar uma renderização com `useOrchStore` parcialmente hidratado, sem a
     chave `paneMissions`.
  2) Pedir ao Jarvis para abrir ou usar um pane shell/agente comum.
- Esperado: sem vínculo de missão, o pane abre na grade global sem erro.
- Observado: a leitura direta de `paneMissions[pane.id]` lançava
  `TypeError`, interrompendo o fluxo de voz.
- Evidência:
  - antes da correção, `npx vitest run
    src/renderer/lib/mission-attention-route.test.ts
    src/renderer/voice/jarvis-action-executor-mcp-result.test.ts
    src/renderer/voice/jarvis-action-executor-sync-repo.test.ts` falhou em
    quatro cenários com `Cannot read properties of undefined`;
  - o check completo do `main` 35045522063 reportou a mesma causa em quatro
    testes de Jarvis.
- (resolvedor) Correcao:
  - Causa raiz: F-351 passou a consultar o vínculo transitório em uma função
    compartilhada, mas ela assumia que snapshots parciais sempre continham o
    mapa `paneMissions`.
  - A função trata o mapa ausente como nenhum vínculo, preservando a rota
    global para panes comuns. Foi adicionado teste de regressão para o
    snapshot parcial em `mission-attention-route.test.ts`.
  - Validacao: os três testes focados (45 testes), `npm run typecheck` e
    `npm run security:renderer-sinks` passaram. Commit `fb16c4b2`
    (`fix(renderer): F-352 — handle partial pane bindings`).
