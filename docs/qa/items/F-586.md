# F-586 — Correção de modelos inexistentes do Google Gemini (gemini-3.8-pro -> gemini-3.8-flash-high)

## F-586 | categoria: provider-compat | severidade: alta | status: corrigido
- Tela/fluxo: Spawning de Panes AGY / Catálogo de Modelos / Squads / Roteamento Jev e Jarvis
- Arquivo:linha: `src/shared/model-defaults.ts:16`, `src/adapters/builtin/agy.json:20`, `src/main/adapters/model-catalog.ts:38`, `resources/model-catalog.json:30`, `resources/model-ranking.json:40`
- Passos:
  1) O operador abria um pane com o agente AGY (Google Gemini/Antigravity) ou acionava o squad/orquestrador Jev para despachar tarefas.
  2) O Nexus IDE tentava utilizar ou migrar para `gemini-3.8-pro-high` ou `gemini-3.8-pro`.
  3) O Google Gemini não possui os modelos `gemini-3.8-pro` ou `gemini-3.8-pro-high`; a linhagem 3.8 do Gemini oferece `gemini-3.8-flash-high`, `gemini-3.8-flash-medium` e `gemini-3.8-flash-low` (conforme verificado via CLI oficial `agy models`). Invocação direta com `--model gemini-3.8-pro-high` gerava rejeição e falha de inicialização ou fallback involuntário.
- Esperado:
  1) Catálogo de modelos, defaults de adapter `agy`, squads e Jarvis devem referenciar modelos oficiais existentes (`gemini-3.8-flash-high`, `gemini-3.8-flash-medium`, `gemini-3.8-flash-low`, `gemini-3.1-pro-high`, `gemini-3.1-pro-low`).
  2) A tabela de migrações automáticas (`RETIRED_MODEL_MIGRATIONS`) deve redirecionar quaisquer referências a `gemini-3.8-pro-high`, `gemini-3.8-pro` e `gemini-3.1-pro-high` para `gemini-3.8-flash-high`.
- Observado:
  - Presença de `gemini-3.8-pro-high` como default no catálogo, causando rejeição ao invocar o modelo inexistente.
- Evidencia:
  - `src/main/adapters/model-catalog.test.ts` (aprovado).
  - `src/main/adapters/adapter-registry.test.ts` (aprovado).
  - `src/shared/squad-model-defaults.test.ts` (aprovado).
  - `src/main/orch/failover-model-rotation.test.ts` (aprovado).
  - `src/main/orch/squad-store.test.ts` (aprovado).
  - `src/main/orch/task-router-quality.test.ts` (aprovado).
  - `src/main/voice/jarvis-action-fastpath.test.ts` (aprovado).
  - `src/renderer/orch/orchestrator-runtime.test.ts` (aprovado).
  - `npm run typecheck` (0 erros).
  - `npm run security:renderer-sinks` (0 sinks).
- (resolvedor) Correcao:
  - Substituído `gemini-3.8-pro-high` por `gemini-3.8-flash-high` no catálogo builtin de adapters (`agy.json`), catálogo de modelos (`model-catalog.ts`, `resources/model-catalog.json`), ranking Jev (`resources/model-ranking.json`), executor Jarvis e defaults de squads.
  - Atualizada a regra em `model-defaults.ts` para migrar automaticamente `gemini-3.8-pro-high`, `gemini-3.8-pro` e `gemini-3.1-pro-high` para `gemini-3.8-flash-high`.
  - Atualizadas todas as suítes de testes associadas para garantir conformidade estrita com o catálogo suportado pela CLI Antigravity.
