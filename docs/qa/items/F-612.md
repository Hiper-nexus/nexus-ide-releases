# F-612 — Redline some da barra depois de atualizar o Nexus

## F-612 | categoria: funcional | severidade: alta | status: corrigido
- Tela/fluxo: atualizar o NexusIDE.app; Ajustes → Uso e cotas → Abrir Redline.
- Arquivo:linha: `src/main/redline/redline-install.ts` (`syncInstalledRedline`,
  `openRedline`); `native/menubar-redline/main.swift` (`entriesForBar`).
- Passos: 1) Instalar o Redline uma vez. 2) Atualizar o Nexus. 3) Procurar o
  extra no topo do Mac. 4) Clicar "Abrir Redline" se o processo já existir.
- Esperado: o companheiro em `/Applications` é substituído pelo binário
  empacotado, relança, e a faixa mostra só contas com leitura de cota.
- Observado: `maybeOfferRedlineInstall` via o marker e não sincroniza. `open`
  num LSUIElement já rodando não reconstrói o extra. A faixa pintava até 8
  contas com `·····` (unknown) e o macOS escondia o item no overflow.
- Evidencia: `/Applications/Nexus Redline.app` ad-hoc (md5 distinto do
  empacotado 0.76.61); `pgrep NexusRedline` vivo; snapshot com 12 entries e
  só GLM/Codex com `usedRatio`.
- (resolvedor) Correção: `syncInstalledRedline` no boot copia se o binário
  diferir e lança se parado. "Abrir" dá pkill+open. Snapshot manda
  `statusBarEntryIds` (máx. 6 com leitura). Validação:
  `npx vitest run src/main/redline/redline-install.test.ts
  src/main/quota/redline-sink.test.ts`.
