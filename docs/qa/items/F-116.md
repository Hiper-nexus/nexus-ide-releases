# F-116 — Sidebar do Nexus desalinhada do padrão Orca (cards, status dots, search ⌘K e remoção do bloco rosa)

## F-116 | categoria: visual / usabilidade | severidade: média | status: corrigido
- Tela/fluxo: Sidebar lateral do Nexus (WorkspaceRail), lista de missões/workspaces e navegação rápida
- Arquivo:linha: `src/renderer/components/product/WorkspaceRail.tsx`, `src/renderer/styles/app-shell.css`, `src/renderer/components/AttentionInbox.tsx`
- Passos: 1) Abrir o NexusIDE após atualização da release 0.74.4. 2) Comparar a sidebar do Nexus com o padrão do Orca (`stablyai/orca`).
- Esperado:
  1) Sidebar seguir a linguagem de design do Orca: tema escuro obsidian/zinc com superfícies translúcidas discretas.
  2) Barra de busca rápida no topo com ícone de lupa, placeholder e atalho `⌘K` (que abre o CommandPalette).
  3) Missões exibidas como cards no padrão Orca (`WorktreeCard`): cantos arredondados, borda sutil, hover elegante, dot de status circular com glow (verde para rodando, âmbar para dormindo, ciano para pronto, etc.).
  4) Metadados limpos no card: chip do repositório/workspace com marca quadrada colorida (`■ HiperGO`), branch Git e status da missão.
  5) Remoção do bloco gradiente rosa/magenta chamativo no botão "Nova missão" (`workspace-rail__mission-cta`), substituído por card clean e sutil com traço pontilhado discreto alinhado ao tema.
  6) Largura do rail ampliada para 200px (dentro do limite contratual do test suite) permitindo respiração dos cards.
- Observado:
  1) A sidebar ainda continha um bloco grande e chamativo em gradiente rosa/magenta ("Nova missão - Descreva o objetivo").
  2) As missões eram exibidas como linhas de texto simples sem o formato de cards com dots de status coloridos do Orca.
  3) Não havia barra de busca com atalho `⌘K` no topo da sidebar.
  4) O usuário reportou: "nao esta igual orca nao" e enviou print com as diferenças.
- Correção (04/09/2026):
  1) `src/renderer/components/product/WorkspaceRail.tsx`:
     - Integrado botão de busca no topo (abaixo do header de identidade) com atalho `⌘K` conectado ao `useCommandPaletteStore`.
     - Atualizado `WorkspaceGroup` para renderizar as missões como cards completos no padrão Orca, com dot de status, linha de cabeçalho, chip de repositório e branch.
     - Adicionada contagem em pill nos grupos (`Em andamento`, `Recentes`).
  2) `src/renderer/styles/app-shell.css`:
     - Redesenhado `.workspace-rail__mission-cta` eliminando o gradiente magenta e adotando superfície translúcida com borda pontilhada sutil e ícone azul ciano.
     - Redesenhada a classe `.workspace-rail__mission` como card arredondado (`rounded-md`, border sutil, background translúcido, hover e active com iluminação).
     - Criadas classes para dot de status pulsante com glow (`.workspace-rail__mission-dot`, status running com emerald glow, blocked com amber, ready com cyan).
     - Criado chip de repositório (`.workspace-rail__mission-repo-chip`) com marca quadrada colorida (`.workspace-rail__mission-repo-mark`).
     - Atualizada largura padrão `--nexus-shell-rail-width` para 200px.
  3) `src/renderer/components/AttentionInbox.tsx`:
     - Atualizado fallback de largura do rail para 200px.
- Validação:
  1) `npx vitest run src/renderer/components/product/WorkspaceRail.test.tsx src/renderer/components/product/ProductStyleContracts.test.tsx src/renderer/components/AttentionInbox.test.tsx src/renderer/App.test.tsx` (53/53 aprovados).
  2) `npm run typecheck` (0 erros).
