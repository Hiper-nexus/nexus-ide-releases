# F-568 — Cabeçalho do pane "treme": título com spinner do CLI muda de largura a cada frame

## F-568 | categoria: visual | severidade: media | status: corrigido

- Tela/fluxo: toolbar do pane (chip "pane N", ícones, título) com o pane em
  atividade (Codex/Claude/Grok rodando).
- Arquivo:linha: `src/renderer/terminal/terminal-host.ts` (os dois listeners
  `onTitleChange` que propagavam o título OSC cru direto ao store, sem
  normalizar/deduplicar/throttle) e `src/renderer/components/PaneToolbar.tsx`
  (título e indicador de atividade sem trava de largura).
- Passos: 1) abrir um pane de CLI (Codex/Claude/Grok); 2) deixar o agente
  trabalhando (spinner ativo reescrevendo o título via OSC 0/2); 3) observar
  o cabeçalho do pane.
- Esperado: o cabeçalho fica estável — chip "pane N" e ícones não se movem
  enquanto o agente trabalha.
- Observado: o CLI reescreve o título do terminal a cada frame do spinner
  ("⠋ nexus-ide", "⠙ nexus-ide", "◑ Brief…", "✳ …"), dezenas de vezes por
  segundo; cada mudança ia direto ao store sem dedupe, o texto do título
  mudava de glifo/largura a cada frame e o toolbar inteiro "tremia"/vibrava.
- Evidência: print do operador, 16/09 —
  `.nexus/attachments/mission-context/mu4h88dg-d86f649d83da10a5-print-2026-09-16T19-11-22.png`.
- (resolvedor) Correção: novo módulo puro `normalizePaneTitle(raw)` em
  `src/renderer/lib/pane-title.ts` remove o glifo de status inicial (braille
  U+2800–U+28FF incl. ⠿, quartos de círculo ◐◑◒◓, família de asteriscos
  ✳✻✽✶✢, ponto médio ·), colapsa espaços e devolve `{ title, activity }`
  — atividade derivada do glifo (braille/círculos/asteriscos → `busy`, ponto
  médio → `idle`, sem glifo → `null`). Os dois handlers `onTitleChange` de
  `terminal-host.ts` (`wireHostTerminalListeners` no caminho de rehydrate e
  `createShellHost` no de criação) passaram a rotear por
  `applyIncomingPaneTitle`, que normaliza, deduplica contra o último título
  já aplicado e só escreve no store (`useLayoutStore.getState().setTitle`)
  com throttle trailing de 250ms — uma rajada de frames diferentes coalesce
  num único write com o valor final; frames que normalizam para o mesmo
  título não geram write nenhum. Como o store nunca mais recebe o glifo, a
  lista de panes e a paleta ⌘K (que leem o mesmo `pane.title`) também
  deixaram de exibi-lo, sem precisar de mudança própria. Em
  `PaneToolbar.tsx`: o título ganhou `font-variant-numeric: tabular-nums`
  (min-width/ellipsis já vinham do CSS global), o slot do indicador de
  atividade (`StateIndicator`) ganhou largura mínima fixa no modo compacto
  (dot/ícone, não texto), e o cabeçalho (`.toolbar__meta`) ganhou
  `contain: layout` para isolar qualquer reflow residual do resto do pane.
  createCliAgentHost (`terminal-host.ts` ~1959) tem um terceiro
  `onTitleChange` fora do escopo desta ficha (fora da lista de handlers
  autorizados) — se o tremor persistir especificamente em panes de CLI
  recém-criados (antes de qualquer hibernate/wake), esse é o handler que
  falta migrar para `applyIncomingPaneTitle`.
  Arquivos: `src/renderer/lib/pane-title.ts` (+`pane-title.test.ts`),
  `src/renderer/terminal/terminal-host.ts` (+testes em
  `terminal-host.test.ts`), `src/renderer/components/PaneToolbar.tsx`
  (+teste em `PaneToolbar.test.tsx`). Validado com
  `npx vitest run src/renderer/lib/pane-title src/renderer/terminal/terminal-host src/renderer/components/PaneToolbar`
  (73 testes, verde), `npm run typecheck` (sem erros nos arquivos desta
  ficha — os erros pré-existentes em `src/main/orch/*` pertencem a outra
  sessão em andamento no mesmo repositório, fora do escopo aqui) e
  `npm run security:renderer-sinks` (0 sinks executáveis).
