# F-025 — Erro de login contado como cota alta

## F-025 | categoria: funcional | severidade: media | status: corrigido
- Fluxo: resumo da frota › quantidade de entradas no limite.
- Arquivo: `src/main/quota/quota-policy.ts`.
- Esperado: cooldown de autenticação pode bloquear spawn, mas não significa consumo alto.
- Observado: qualquer cooldown contava como cota alta quando havia uma janela conhecida, mesmo com uso de 10%.
- Evidência: teste RED com cota baixa e `cooldownKind=auth`.
- Correção: contador considera apenas a proporção de uso; bloqueio por autenticação continua preservado na disponibilidade.
- Validação: 144 testes de quota/native auth isolados; typecheck e renderer sinks.
