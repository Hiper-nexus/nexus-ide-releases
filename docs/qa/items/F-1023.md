# F-1023 — Casos de teste registrados em laço sumiam do relatório sem aviso (QLT-06)

## F-1023 | categoria: qualidade | severidade: media | status: corrigido
- Tela/fluxo: `npm run lint:oxlint -- --quiet` (CI e `npm run lint`) → plugin local `oxlint-plugin-nexus`.
- Arquivo:linha (antes): 17 registros de caso dentro de `for`/`.forEach` em 12 arquivos de teste, entre eles `src/main/pty/agent-model-argv.test.ts:23-35` (dois `for` aninhados com `continue` antes do `it`), `src/main/orch/intent-router-matrix.test.ts:73`, `src/renderer/overlay/overlay-layer.test.tsx:95` e `scripts/darwin-pty-supervisor.test.mjs:1145,1283`.
- Passos: 1) Registrar casos com `for (const caso of tabela) it(\`...${caso}\`, ...)`. 2) Esvaziar a tabela, ou deixar um `continue`/`break` pular linhas dela.
- Esperado: a tabela é declarada (`it.each`/`describe.each`/`it.for`) e cada linha vira um caso com nome no relatório e no `--testNamePattern`.
- Observado: nada no lint impedia o laço; um `continue` errado (o padrão do `agent-model-argv`) ou uma tabela vazia apagava casos e a suíte seguia verde.
- (resolvedor) Correcao: regra nova `nexus/no-test-in-loop` (`oxlint-plugin-nexus/rules/no-test-in-loop.mjs`, ideia do T3 Code @ 26285ab, código escrito aqui), ligada como `error` no `.oxlintrc.json`. Acusa `it`/`test`/`describe` (com `.only`/`.skip`/`.concurrent` e `it.runIf(c)(...)`) dentro de laço ou de callback de `.forEach`/`.map`/`.flatMap`, só em `*.test.*`/`*.spec.*` (no produto `describe`/`test` são helpers locais: 39 acusações falsas em `delegation-supervisor.ts`, `browser-automation.ts` e outros 7 antes de restringir; `suite` também saiu da lista, porque é variável local em `turn-end-handoff.integration.test.ts` e `gamification-service.test.ts`). Para no primeiro teste de fora: o `describe` dentro do laço responde, não os `it` dele. As 17 ocorrências viraram `it.each`/`describe.each`; as duas do supervisor nativo viraram `it.for` (usam o contexto `{ skip }`, que o `it.each` não passa) e a do hook nativo `it.runIf(runNative).each`. Nenhuma supressão.
- Validacao: `oxlint-plugin-nexus/rules/no-test-in-loop.test.mjs` no `RuleTester` do oxlint — 6 casos inválidos (for...of, forEach com describe, `it.only`/`test.skip` sem chaves, laços aninhados com `continue`, `it.runIf`, `.map`) que precisam ser acusados e 5 válidos (`it.each`, `it.for`, laço no corpo do teste, `suite.x.get` e `/a/.test()`, arquivo de produto). Antes da conversão o oxlint dava 17 erros; depois `oxlint --quiet src server scripts` → 0 erros. Os 10 arquivos convertidos que rodam sem nativo, mais os testes do plugin: 325/325. `native-heavy-tool-hook.test.ts` (chama o `claude` real) e `darwin-pty-supervisor.test.mjs` (supervisor nativo) só foram coletados (`vitest list`, sem executar corpo), com os nomes novos. `npm run typecheck` verde.
