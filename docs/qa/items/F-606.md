# F-606 — Aba do espaço ("Meus terminais") não tinha opção de renomear

## F-606 | categoria: usabilidade | severidade: média | status: corrigido
- Tela/fluxo: Terminais → barra "Abas:" → chip do espaço do operador
  ("Meus terminais N").
- Arquivo:linha: `src/renderer/components/product/TerminalWorkspace.tsx`;
  `src/renderer/state/layout-store.ts` (`renamePaneSpace`).
- Passos: 1) Abrir um espaço pelo "Montar meus terminais". 2) Tentar renomear
  a aba do espaço na barra de filtros.
- Esperado: o chip do espaço oferece edição do nome, como o título do pane já
  oferece no PaneToolbar (duplo clique → edição inline).
- Observado: o chip só filtrava o mosaico. Não existia `renamePaneSpace` nem
  affordance de edição — o pedido anterior de "opção de editar" nunca tinha
  sido implementado (o comentário de `nextPaneSpaceTitle` já previa "espaço
  que o operador renomeou", mas a ação nunca foi ligada).
- (resolvedor) Correção: `renamePaneSpace(spaceId, title)` no layout-store
  renomeia todos os panes carimbados com o espaço (panes adotados por missão
  não são tocados; título vazio ignorado). Chip de espaço ganha duplo clique
  com edição inline (Enter/blur gravam, Esc cancela), tooltip "duplo clique
  para renomear" e CSS `terminal-workspace__chip-rename`. Chips de missão e
  "Painéis soltos" não entram em edição. O rascunho vem do carimbo real do
  pane, não do rótulo com sufixo de desambiguação ("Título #2").
  Validação: `npx vitest run src/renderer/state/layout-store.test.ts
  src/renderer/components/product/TerminalWorkspace.test.tsx` (180/180),
  `npm run typecheck`, `npm run security:renderer-sinks` (0 sinks).
