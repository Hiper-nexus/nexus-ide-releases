# F-549 — Smoke Windows é apresentado como instalação Squirrel danificada

## F-549 | categoria: build | severidade: media | status: corrigido
- Tela/fluxo: pacote Windows aberto pelo smoke local de validação e modal de
  atualização.
- Arquivo:linha: `src/main/updater.ts:345`.
- Passos:
  1) Empacotar o aplicativo com Forge no Windows.
  2) Abrir o pacote diretamente pelo smoke (`nexus-smoke-test`), sem passar
     pelo instalador Squirrel.
  3) Observar o modal de atualização.
- Esperado: o modo de validação local fica silencioso para atualizações e não
  se apresenta como uma instalação do usuário corrompida.
- Observado: o modal exibiu `Instalação Squirrel incompleta: Update.exe não
  foi encontrado.`, embora o executável pertencesse ao pacote de teste local.
- Evidencia: screenshot do operador
  `codex-clipboard-c45b6d9e-b92b-4145-b20b-37ffd5a486e8.png`; teste
  inicialmente falho `src/main/updater.test.ts` em 2026-09-16, pois a
  validação do Squirrel acontecia antes do modo offline do smoke.
- (resolvedor) Correcao:
  - `UpdateManager.init()` aplica primeiro o modo offline explícito. Assim, o
    smoke preserva o contrato de IPC sem rede e sem validar um layout Squirrel
    que deliberadamente não existe no diretório de teste.
  - A validação de `Update.exe` para uma instalação real empacotada permanece
    logo após essa guarda; uma instalação Squirrel realmente incompleta ainda
    é reportada como tal.
  - Commit `10595a2e` (`fix(updater): F-549 — keep packaged smoke offline`).
  - Validação: `npx vitest run src/main/updater.test.ts` (13 testes) passou.
