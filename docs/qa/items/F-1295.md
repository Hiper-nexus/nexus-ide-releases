# F-1295 — Smoke empacotado não exige os recursos que o Main abre em runtime

## F-1295 | categoria: funcional | severidade: media | status: corrigido
- Tela/fluxo: gate do app empacotado (`scripts/smoke-packaged-app.mjs`, `runPackagedSmoke`).
- Arquivo:linha (antes): `scripts/smoke-packaged-app.mjs` (`requiredNativeArtifactGlobs`, por volta de 681) só exigia bindings nativos, `wake/`, `icon.ico` e notices. O Main lê em runtime, sem asserção no pacote: `Resources/heavy-command` (`src/main/orch/native-heavy-preload.ts:10,23`), `Resources/mission-shims/nx-shim.cjs` (`src/main/orch/mission-shim-runtime.ts:218`), `Resources/shell-integration/nexus-osc133.zsh` (`src/main/terminal/shell-integration-env.ts:26`), `Resources/model-ranking.json` (`src/main/eval/eval-ipc.ts:28`), `Resources/pets/manifest.json` (`src/main/pet/pet-library.ts:48`), `Resources/agent-detection/claude.toml` e `Resources/ghostty/ghostty-vt.wasm` (`src/main/detect/manifest.ts:361`, `src/main/detect/ghostty-runtime.ts:248`), `Resources/design-system-sensor.mjs` (`src/main/context/context-doctor.ts:626`).
- Passos: 1) Empacotar sem um `extraResource` (ou com o diretório vazio de sentinela). 2) Rodar o smoke.
- Esperado: o smoke reprova antes de lançar o binário.
- Observado: `requiredResourceArtifacts` não existia; um `Resources` sem `shell-integration/` ou sem `nx-shim.cjs` passava no gate.
- Evidencia: RED com a fonte revertida — `requiredResourceArtifacts is not a function` em `scripts/smoke-packaged-app.test.mjs` (teste F-1295). Os 135 testes do fluxo estavam verdes antes da mudança.
- (resolvedor) Correcao: `requiredResourceArtifacts()` lê `extraResource` de `forge.config.ts` (cada entrada tem de existir em `Resources/<basename>`; ternários de `process.platform` seguem o host do build; spread desconhecido falha fechado) e exige um sentinela por diretório (`preload.cjs`, `nx-shim.cjs`, `nexus-osc133.zsh`, `manifest.json`, `claude.toml`, `ghostty-vt.wasm`). `runPackagedSmoke` chama `assertPackagedResourceArtifacts`.
- Validacao: `node node_modules/vitest/vitest.mjs run scripts/smoke-packaged-app.test.mjs forge.config.test.ts src/main/orch/builtin-squads.test.ts` — 139 verdes depois da correção. RED reproduzido revertendo só `scripts/smoke-packaged-app.mjs`.
- Limite: o supervisor Darwin (`resources/native/darwin/nexus-pty-supervisor`) é gerado no build e não está nesta worktree; o gate exige o basename no pacote, não o arquivo no git. Não houve smoke de um `.app` recém-empacotado.
