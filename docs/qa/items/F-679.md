## F-679 | categoria: funcional | severidade: media | status: corrigido
- Tela/fluxo: roteamento (`nexus_route_task`, auto-route do `nexus_pane_spawn`), UI de providers — tudo que lê `loadModelCatalog`.
- Arquivo:linha: `src/main/adapters/model-catalog.ts` (`loadModelCatalog`: USER por último, sempre vencendo).
- Passos: 1) Máquina que semeou `~/.nexus/model-catalog.json` numa versão antiga (`seedLocalModelCatalogFromPublished` só grava se o arquivo não existe; o refresh remoto dá 404 no repo privado). 2) Atualizar o app. 3) Rotear uma tarefa média.
