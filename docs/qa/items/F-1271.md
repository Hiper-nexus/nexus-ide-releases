# F-1271 — Toda tarefa de bug virava "visual" e a entrega caía para partial

## F-1271 | categoria: funcional | severidade: alta | status: corrigido
- Tela/fluxo: spawn de worker → `visualTaskAtSpawn` → `checkVisualHandoff` no `nexus_handoff_submit`.
- Arquivo:linha (antes): `src/main/orch/visual-handoff-gate.ts:28-33`. `visualTaskRequirement` classificava o `initialPrompt` inteiro, já com os blocos de contexto que o Nexus monta na frente.
- Passos:
  1. Projeto cujo `<business-model>` tem invariantes de UI. O Nexus IDE tem a `[projeto#27] O PAINEL é superfície Nexus escura… popover… #111013 cabeçalho/rodapé… tema claro`.
  2. `nexus_pane_spawn` de um writer com uma tarefa de backend, ex.: "Corrigir bug no nexus_file_search…".
  3. O writer corrige, testa e entrega `success`.
- Esperado: tarefa de backend sem exigência de captura visual. Entrega `success` e o helper fecha sozinho.
- Observado:
  - A entrega vira `partial` com `[verificação visual pendente]` e "A tarefa visual ainda precisa de uma captura do navegador".
  - Como não é `success`, o helper não fecha sozinho e segue ocupando vaga.
  - Com o teto de 12 panes, spawns seguintes foram recusados (ver F-1270).
- Evidencia:
  - Ao vivo, na missão de 12/10 no app 0.76.238, três entregas de código sem nada visual voltaram `partial` por isso:
    - F-1251, busca de arquivos;
    - F-1255, diálogos do Main;
    - a revisão de estado do renderer.
  - Sonda com o classificador real: a tarefa sozinha dá `isUiWorkText=false`; com o bloco `<business-model>` na frente, `true`.
  - RED (fonte anterior), `visual-handoff-gate.test.ts` › "F-1271…": `expected { since: 1000, …(1) } to be undefined`.
- (resolvedor) Correcao:
  - `prompt-context-blocks.ts` ganha `withoutMountedPromptContextBlocks`, que devolve o texto depois dos blocos montados na frente. Ele usa o mesmo reconhecimento de abertura que impede montagem duplicada.
  - `visualTaskRequirement` classifica só esse texto.
  - Continua igual:
    - uma tarefa de UI continua visual mesmo com o bloco na frente;
    - citar a tag no meio da tarefa não conta como montagem.
- Validacao: `visual-handoff-gate.test.ts` + `prompt-context-blocks.test.ts` 17/17 (RED 1/1 com a fonte anterior).
