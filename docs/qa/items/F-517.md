# F-517 — Notificação proativa e banner visível na UI ao detectar nova atualização do NexusIDE

## F-517 | categoria: funcional | severidade: média | status: corrigido
- Tela/fluxo: Interface principal / WorkspaceBar / Overlays (`UpdateModal.tsx`, `updater.ts`, `overlays.css`)
- Arquivo:linha: `src/main/updater.ts:42`, `src/renderer/components/UpdateModal.tsx:148`, `src/renderer/styles/overlays.css:55`
- Passos:
  1) Abrir o NexusIDE ou trazer a janela para o foco quando há uma nova versão publicada no GitHub Releases.
  2) Observar se a interface alerta proativamente o usuário sobre a atualização disponível.
- Esperado:
  - O aplicativo deve checar rapidamente no boot (3s em vez de 20s) e ao focar a janela (se > 15min).
  - Sempre que uma nova versão estiver disponível (`available`) ou pronta para reiniciar (`ready`), um banner flutuante destacado (`UpdateBannerNotice`) deve aparecer no topo da tela com CTA direto `[Atualizar agora]` ou `[Reiniciar agora]`.
  - O botão de status de atualização na barra de ferramentas deve ter estilo destacado e pulsante (`update-status-btn--available`) em vez de texto plano cinza.
- Observado:
  - O usuário não era notificado visualmente a menos que clicasse manualmente no botão minúsculo de 11px na barra de ferramentas.
  - A checagem inicial demorava 20 segundos após o boot, não ocorria ao alternar de janelas e não existia classe CSS para o estado `available`.
- Evidencia:
  - Reduzido `BOOT_CHECK_DELAY_MS` para 3_000ms e adicionado listener de foco de janela no `UpdateManager`.
  - `useUpdateState` dispara checagem proativa em background na montagem caso o estado seja `idle` ou a checagem anterior tenha mais de 15 minutos.
  - Criado componente `UpdateBannerNotice` exibido automaticamente quando há versão disponível/pronta, com ações de atualizar, ver notas e dispensar.
  - Estilização completa de `.update-banner` e `.update-status-btn--available` em `overlays.css`.
  - Testes unitários adicionados e validados em `src/renderer/components/UpdateModal.test.tsx` (4 testes verdes).
- (resolvedor) Correcao:
  - `src/main/updater.ts`: delay de 3s no boot e checagem em `browser-window-focus`.
  - `src/renderer/components/UpdateModal.tsx`: checagem proativa no `useUpdateState` e componente `UpdateBannerNotice` integrado no `UpdateNotifier`.
  - `src/renderer/styles/overlays.css`: regras CSS para `.update-status-btn--available` e `.update-banner`.
  - `src/renderer/components/UpdateModal.test.tsx`: cobertura para o banner e ações de 1 clique.
