# F-1356 — o digest do pane devin vira dígitos soltos, e o full mostra só o spinner

## F-1356 | categoria: funcional | severidade: media | status: corrigido
- Tela/fluxo: `nexus_pane_read` (digest) de worker Devin com redesenho de spinner / TUI.
- Arquivo:linha (antes):
  - `src/main/orch/pane-output-digest.ts:310`: `frameKey` só fundia linhas com `TICKING_PATTERN` (`ms|s|m|%`), deixando dígitos soltos de contador sem deduplicação.
  - `src/main/orch/pane-output-digest.ts:328`: linhas com spinner + contador não eram descartadas quando a tela não tinha texto legível.
- Passos:
  1. Worker Devin em execução redesenhando spinner braille (`⠋ 5`, `⠙ 6`, etc.).
  2. Chamada `nexus_pane_read` com mode `digest`.
- Esperado: quadros de spinner e contador colapsam; se a tela não contém texto legível, o digest relata "TUI sem texto legível" em vez de emitir dígitos soltos como "5\n6". Quando há texto real da resposta/ferramentas, o texto real aparece sem poluição de dígitos de spinner.
- Observado: `nexus_pane_read` devolveu `" 5\n 6"` com 58 linhas omitidas pelo teto de caracteres.
- Evidencia (RED, fonte anterior):
  - `src/main/orch/pane-output-digest.test.ts` › "F-1356: tail só com quadros de spinner/contador devolve aviso legível em vez de dígitos soltos":
  - `AssertionError: expected ' 5\n 6' to match /spinner|sem texto/`.
- Correção:
  - Em `src/main/orch/pane-output-digest.ts`:
    - `frameKey` agora trata linhas compostas apenas por dígitos (`/^\d+$/`) como quadro de contador (`'0'`), colapsando-as entre si.
    - Linhas compostas apenas por glifos de spinner e dígitos/espaços são identificadas como quadros de contador (`isSpinnerCounter`) e marcadas para descarte (`drop: true`) para não poluir o conteúdo real.
    - Se todas as linhas restantes forem vazias ou compostas apenas por dígitos nus sem nenhum sinal ou texto legível, `digestPaneTail` retorna `text: 'TUI sem texto legível'`.
- Validacao:
  - `npx vitest run src/main/orch/pane-output-digest.test.ts`: 20/20 passaram (inclui teste com tail de spinner isolado e teste com texto real preservado).
