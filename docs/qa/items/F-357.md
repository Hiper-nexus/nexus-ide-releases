# F-357 — Retomada de saída após descarte perde ressincronização ANSI

## F-357 | categoria: funcional | severidade: alta | status: corrigido
- Tela/fluxo: terminal oculto com animações de TUI; revelação/foco depois de acumular saída.
- Arquivo:linha: `src/renderer/terminal/terminal-output-scheduler.ts` (`replaceBacklogWithWarning`, `enqueueChunk`, `writeTerminalOutput`).
- Passos: 1) Reter 4.096 chunks de spinner e um fragmento `ESC [` em background. 2) Retomar e drenar o aviso de descarte. 3) Entregar o restante `31mBROKEN-ANSI-TAIL` antes de uma nova sequência completa.
- Esperado: após descarte, ignorar o fragmento até uma fronteira segura de ANSI/newline, inclusive se a fila já drenou.
- Observado: a fila vazia era removida junto com `resyncToNewlinePending`; tanto a rota foreground imediata quanto uma nova fila background entregavam a cauda de ANSI como texto literal.
- Evidencia: testes focados falharam nos dois caminhos antes da correção. O limite de 4.096 chunks também pode ser atingido abaixo de 2 MB; o aviso antigo afirmava incorretamente que sempre houve mais de 2 MB. Defeito encontrado durante F-356; não prova o gatilho exato do print do operador.
- (resolvedor) Correcao: estado de ressincronização passa a pertencer ao terminal em `WeakSet`, fora da fila descartável; todo novo payload passa pelo filtro antes de escolher entrega imediata ou fila. Descarte final do terminal remove o estado. Aviso descreve o limite de backlog sem inventar volume.
- Validacao: `npx vitest run src/renderer/terminal/terminal-output-scheduler.test.ts` passou (31 testes no arquivo atualizado; 60 contando a cópia descoberta pela configuração atual). As duas regressões novas falharam antes do patch. `npm run typecheck` passou; `npm run security:renderer-sinks` retornou 0 sinks; `git diff --check` passou. Revisão independente confirmou isolamento entre terminais, callbacks, fronteira newline/ESC, descarte/reutilização e ausência de retenção por WeakSet.
