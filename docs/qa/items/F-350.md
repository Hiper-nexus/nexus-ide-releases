# F-350 — Modal de atualização preso no canto esquerdo

## F-350 | categoria: visual | severidade: media | status: verificado
- Tela/fluxo: camada global de overlay e modal de atualização no Windows.
- Arquivo:linha: `src/renderer/styles/overlay-layer.css:8-24`
- Passos: 1) Abrir o NexusIDE instalado no Windows. 2) Exibir o aviso de atualização.
- Esperado: O modal `position: fixed` fica ancorado no viewport, no canto superior direito.
- Observado: O modal aparece deslocado/cortado à esquerda, apesar do CSS do modal usar `inset` e `place-items` relativos à viewport.
- Evidencia: screenshot fornecido pelo operador; teste RED reproduzindo `transform` no ancestral `.overlay-layer`.
- (resolvedor) Correcao: Removidos `transform` e `-webkit-transform` de `.overlay-layer`; esses transforms criavam um containing block de 0×0 e faziam filhos `position: fixed` ignorarem a viewport. Commit `a4a1f238`. Validação: suíte focada atualizada (204 testes), `npm run typecheck` e `npm run security:renderer-sinks` passaram.
