# F-530 — Barra lateral (WorkspaceRail) cortando conteúdo, selo ATUAL encolhido para ATU e limite artificial de largura (280px expandido para 480px)

## F-530 | categoria: visual | severidade: media | status: corrigido
- Tela/fluxo: Barra lateral esquerda (WorkspaceRail) / redimensionamento e exibição de projetos e cotas
- Arquivo:linha: `src/renderer/state/rail-width-store.ts:13`, `src/renderer/styles/app-shell.css:746`, `src/renderer/styles/app-shell.css:763`
- Passos:
  1) Abrir o Nexus IDE com múltiplos workspaces, nomes longos de diretórios ou barras de cota visíveis.
  2) Observar o selo `ATUAL` do projeto ativo e o botão de busca `[⌘K]`.
  3) Tentar arrastar a borda do rail para expandir e ler os nomes completos.
- Esperado:
  - O selo `ATUAL` nunca deve ser truncado (não encolher para `ATU`).
  - O nome do projeto deve truncar com reticências antes de afetar os badges adjacentes.
  - O usuário deve conseguir redimensionar a barra lateral confortavelmente (até 480px) para acomodar caminhos e cotas.
- Observado:
  - `RAIL_WIDTH_MAX` estava travado em apenas `280px`.
  - `.workspace-rail__workspace-current` possuía `flex: 0 1 auto; min-width: 0; overflow: hidden; text-overflow: ellipsis;`, permitindo que o selo sofresse contração e ficasse cortado como `ATU`.
  - `.workspace-rail__workspace-title .workspace-rail__row-label` possuía `min-width: 4ch;`, impedindo sua retração anterior ao selo.
- Evidencia:
  - `RAIL_WIDTH_MAX` ampliado para `480px` e padrão ajustado para `260px` em `src/renderer/state/rail-width-store.ts`.
  - `.workspace-rail__workspace-current` definido com `flex: 0 0 auto; flex-shrink: 0; white-space: nowrap;`.
  - `.workspace-rail__workspace-title .workspace-rail__row-label` ajustado para `min-width: 0; flex: 1 1 auto;`.
  - Testes validados em `src/renderer/state/rail-width-store.test.ts` e `src/renderer/components/product/WorkspaceRail.test.tsx`.
- (resolvedor) Correcao:
  - `src/renderer/state/rail-width-store.ts`: `RAIL_WIDTH_MAX = 480`, `RAIL_WIDTH_DEFAULT = 260`.
  - `src/renderer/styles/app-shell.css`: regras CSS corrigidas para preservar integridade de selos e possibilitar reticências limpas.
