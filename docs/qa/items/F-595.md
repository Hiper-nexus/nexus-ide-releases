# F-595 — Login do Kimi abre página em chinês (kimi.com) e não dá para autenticar com Google

## F-595 | categoria: usabilidade | severidade: alta | status: corrigido
- Tela/fluxo: Ajustes → contas / `+ Pane` → login da CLI Kimi.
- Arquivo:linha: `src/adapters/builtin/kimi.json`; `src/shared/kimi-login-command.ts`; `src/shared/account-login-commands.ts`
- Passos: 1) Clicar para logar no Kimi. 2) O CLI abre o browser no device-code flow.
- Esperado: tela de autenticação internacional em inglês (`kimi.ai`) com Google etc.
- Observado: página em chinês (`kimi.com` / region `mainland-cn`); o operador não consegue logar.
- Evidencia: `~/.kimi-code/region` = `mainland-cn`; `kimi login --help` expõe `--region mainland-cn|global`; sem a flag o CLI cai na região gravada/auto-detectada.
- (resolvedor) Correcao: o comando de login do Nexus passa a ser `kimi login --region global`, salvo locale OS `zh*` (`kimiLoginCommand`). Adapter, `ACCOUNT_LOGIN_COMMANDS` e o `loginCommand` do store usam essa política.
