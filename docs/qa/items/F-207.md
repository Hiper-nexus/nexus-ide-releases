# F-207 — Codex renova credencial fora da trava da conta realmente escolhida

## F-207 | categoria: funcional | severidade: alta | status: corrigido
- Tela/fluxo: panes Codex de múltiplas contas, seleção automática, retomada e failover.
- Arquivo:linha: `src/main/pty/pty-ipc.ts`; `src/main/adapters/managed-auth-spawn-gate.ts`; `src/main/orch/main-owned-pane-runtime.ts`; `src/main/orch/failover-mission-respawn.ts`.
- Passos: abrir dois panes sem accountId explícito com token gerenciado antigo; seleção escolhe uma conta diferente do perfil nativo, ou auth foi removida após o último pane sair e precisa ser materializada do cofre.
- Esperado: selecionar e materializar a conta primeiro; coordenar o refresh no auth.json que a CLI realmente usará; manter a mesma conta no processo, no tracking e no resume.
- Observado: gate consultava request.accountId/perfil nativo antes da seleção/materialização. Arquivo ausente era considerado fresco. O caminho Main-owned/failover também ignorava a espera; timeout do follower liberava spawn com refresh token ainda velho.
- Evidencia: regressões sintéticas reproduziram a ordem errada, identidade errada de arquivo, spawn antes do gate e promoção insegura após timeout. Nenhuma rotação de token real foi executada pelos testes.
- (resolvedor) Correcao: gate recebe o ambiente da preparação concluída, preservada durante o await; autoridade Main revalidada antes e depois da espera. Timeout impede o follower de concorrer com o primeiro refresh. Failover usa o caminho assíncrono. Identidade interna `selectedAccountId` acompanha request físico, adoption, tracking e apresentação; conflito com pin explícito é recusado. Só o renderer confiável recebe accountId no resultado PTY para persistir o pane; recibos MCP continuam mascarados.
- Renderer: se a consulta inicial de contas falhar, o pane salva a conta confirmada pelo Main; conta do outro pane não muda. A UI não inventa uma conta a partir do nome/e-mail.
- Validacao: `npx tsc --noEmit`; `npx vitest run` dos testes tocados (pty-ipc, pty-ipc-mission-resume, managed-auth-spawn-gate, main-owned-pane-runtime, failover-mission-respawn, tool-util-workspace, mission-fast-lane*, pane-registry-main-owned, terminal-host); `npm run security:renderer-sinks`. Todos verdes.
