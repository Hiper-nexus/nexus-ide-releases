# F-118 — Layout cortando na sidebar e cabeçalho por largura insuficiente e desalinhamento macOS

## F-118 | categoria: visual / layout | severidade: alta | status: corrigido
- Tela/fluxo: Shell geral da interface (AppShell), barra de navegação lateral (WorkspaceRail) e cabeçalho (product-header)
- Arquivo:linha: `src/renderer/styles/app-shell.css`, `src/renderer/components/AttentionInbox.tsx`, `src/renderer/components/product/ProductStyleContracts.test.tsx`, `DESIGN.md`
- Passos:
  1) Abrir o NexusIDE no macOS.
  2) Observar a barra lateral com os novos cards de missão estilo Orca.
  3) Observar o botão "+ Novo", o card "Nova missão", os títulos de missão e o rodapé de Cotas.
  4) Observar o topo da janela onde o badge de update (`⇧ v0.74.4`) e sininho de notificações se encontram com a sidebar.
- Esperado:
  1) A sidebar deve ter largura suficiente (250px, padrão Orca) para exibir títulos de missão sem truncamento precoce, tags de repositório e branches completas.
  2) O botão "+ Novo" não deve ter o texto cortado ou comprimido.
  3) O card "Nova missão" deve exibir o subtítulo em 2 linhas limpas com espaçamento adequado.
  4) O cabeçalho (`product-header`) no macOS deve respeitar a área segura da barra de título (`padding-top: 32px`), alinhando-se perfeitamente com o cabeçalho da sidebar e sem colar elementos no topo da janela.
- Observado:
  1) O usuário reportou: "cortando lauotu aqui" e enviou captura de tela com retângulo vermelho mostrando o corte no botão "+ Novo", nas missões e no rodapé.
  2) A variável `--nexus-shell-rail-width` estava limitada a 200px por causa de um teste legado.
  3) `.product-header` não tinha `padding-top` no macOS, fazendo com que `⇧ v0.74.4` ficasse colado no pixel 0 do topo da janela e desalinhado do cabeçalho da sidebar por 32px.
- Correção (04/09/2026):
  1) `src/renderer/styles/app-shell.css`:
     - `--nexus-shell-rail-width` atualizada de 200px para 250px.
     - Adicionado `flex-shrink: 0` e `white-space: nowrap` ao `.workspace-rail__new` para prevenir quebra ou corte.
     - Ajustados `.workspace-rail__mission-cta`, `.workspace-rail__mission` e `.workspace-rail__quota-name` (max-width 135px) para respiração visual e legibilidade.
     - Configurado `.product-header` com `display: flex`, `gap: var(--space-2)`, `padding: 0 var(--space-3)` e `:root[data-platform='mac'] padding-top` com `-webkit-app-region: drag` para alinhamento horizontal contínuo no macOS.
  2) `src/renderer/components/AttentionInbox.tsx`:
     - Atualizado fallback de largura do rail para 250px.
  3) `src/renderer/components/product/ProductStyleContracts.test.tsx`:
     - Ajustada faixa permitida de largura do rail para até 280px.
  4) `DESIGN.md`:
     - Atualizada especificação do rail para 250px (faixa permitida: 200–280px).
- Validação:
  1) `npx vitest run src/renderer/components/product/ProductStyleContracts.test.tsx src/renderer/components/product/WorkspaceRail.test.tsx src/renderer/components/product/AppShell.test.tsx src/renderer/components/AttentionInbox.test.tsx src/renderer/App.test.tsx` (56/56 aprovados).
  2) `npm run typecheck` (0 erros).
  3) `npm run security:renderer-sinks` (0 sinks).
