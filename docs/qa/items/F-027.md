# F-027 — Quota de assinatura atribuída a uma origem API key

## F-027 | categoria: funcional | severidade: alta | status: corrigido
- Fluxo: cota Claude/Codex com autenticação por API key, incluindo conta Anthropic pinada.
- Arquivos: `src/main/quota/quota-service.ts`, `src/main/quota/provider-live-usage.ts`.
- Esperado: origem API key não consulta credenciais OAuth de assinatura; cache distingue o modo de autenticação.
- Observado: sem upstream não-default, o binding voltava à sonda OAuth do adapter. Uma conta API key podia receber dados de assinatura, e trocar o modo mantinha a observação anterior durante o TTL.
- Evidência: quatro testes RED para Claude API, Codex API, conta Anthropic API pinada e mudança de modo no mesmo upstream.
- Correção: origem API key gera binding API explícito; rotas sem quota API compatível permanecem desconhecidas, sem ler OAuth. Cache inclui authMode. Mantida a precedência real do spawn: upstream nativo explícito antes da estratégia geral, enquanto conta de assinatura pinada usa a própria conta.
- Validação: 144 testes de quota/native auth em 17 arquivos com HOME temporário e resolvers simulados; typecheck e renderer sinks.
