# F-415 — Token Cloudflare com prefixo novo fora da redação

## F-415 | categoria: seguranca | severidade: alta | status: corrigido
- Tela/fluxo: texto enviado a modelos e captura visual do navegador.
- Arquivo:linha: `src/shared/vision-ipc.ts:33`, `src/main/decision-models/decision-redaction.ts:40`.
- Passos: 1) Exibir um token sintético `cfut-` em texto, sem label nem input. 2) Executar redação textual e coleta de máscaras.
- Esperado: texto substituído por `[REDACTED]` e área incluída na máscara de pixels.
- Observado: formato prefixado Cloudflare não estava nas regras; texto permanecia e a área não era mascarada.
- Evidencia: três regressões falharam em `cloudflare-prefix-red.log`; nenhuma credencial real foi usada nos testes nem há evidência de exposição real.
- (resolvedor) Correcao: matcher comum para tokens de usuário/conta `cfut-`/`cfat-`, reutilizado pelo texto Main e pelas leituras/retângulos do browser. Visão permanece optativa e desligada na instalação do operador.

- Validação: RED em três regressões; GREEN em 95 testes focados (incluindo metadata), `npm run typecheck` e `npm run security:renderer-sinks` (zero sinks). Matcher textual e retângulo para token solto verificados.
