# F-524 — Resolver Windows pode escolher shim npm incompatível com ConPTY

## F-524 | categoria: funcional | severidade: media | status: corrigido
- Tela/fluxo: descoberta e abertura de CLIs instaladas globalmente pelo npm no
  Windows.
- Arquivo:linha: `src/main/path-resolver.ts` (`lookupInPath`) e node-pty
  `WindowsPtyAgent`.
- Passos: 1) instalar uma CLI npm que cria `codex`, `codex.cmd` e `codex.ps1`;
  2) resolver o nome bare `codex`; 3) iniciar o caminho retornado via node-pty.
- Esperado: descoberta e spawn escolhem um executável nativo ou aplicam uma
  estratégia de wrapper Windows revisada e segura.
- Observado: o resolver testa primeiro o arquivo sem extensão e considera todo
  arquivo regular executável no Windows. O node-pty empacotado entrega `file` e
  a linha de comando diretamente ao ConPTY, sem wrapper específico para `.cmd`.
- Evidencia:
  - `crash-reports.json` local registrou o utility process
    `node.mojom.NodeService` terminando durante o spawn do pane; o host PTY
    sintetizou o `code -1` visto no terminal.
  - Nesta máquina, `codex` era um shim `#!/bin/sh`, enquanto `codex.cmd` e
    `codex.exe` coexistiam no mesmo diretório. O teste real de node-pty contra
    o `.cmd` retornou `codex-cli 0.154.0` e exit code 0.
  - O teste de regressão em `src/main/path-resolver.test.ts` primeiro falhou ao
    resolver `codex.cmd` explicitamente e agora cobre shim sem extensão,
    launcher `.cmd` e cache antigo.
- (resolvedor) Correcao:
  - Causa raiz: `lookupInPath` aceitava primeiro qualquer arquivo regular no
    Windows. Isso selecionava o shim POSIX sem extensão que o npm instala ao
    lado do launcher Windows e o encaminhava diretamente ao ConPTY.
  - `src/main/path-resolver.ts` agora aceita somente `.exe`, `.com`, `.cmd` e
    `.bat` como alvo PTY no Windows, consulta `PATHEXT` antes de qualquer bare
    shim e ainda preserva um launcher já explicitamente sufixado.
  - `src/main/path-resolver.test.ts` cobre o launcher ao lado do shim, o cache
    legado e o nome `.cmd` explícito. Commit `641c10d6`
    (`fix(pty): F-524 — prefer native Windows CLI launchers`).
  - Validacao: `npx vitest run src/main/path-resolver.test.ts` (17 testes),
    `npm run typecheck` e `npm run security:renderer-sinks` passaram.
