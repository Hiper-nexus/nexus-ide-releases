# F-1413 — Painel Git estreito: bagunça visual

## F-1413 | categoria: layout | severidade: média | status: corrigido
- Tela/fluxo: painel lateral Git (inspector) em largura estreita (~230–380 px CSS).
- Arquivos: `src/renderer/styles/git-scm.css`, `src/renderer/components/GitPanelBody.tsx` (cabeçalho do repo), `src/renderer/components/diffs/DiffFileTree.tsx` (linha de arquivo).
- Observado (print do operador): nome da branch quebrava caractere a caractere em 6 linhas com pull/push/atualizar por cima; sub-abas cortadas ("Altera…", "Hist…", "Iss…"); ícone reverter por cima do nome do arquivo; tooltip nativo do caminho completo vazando para fora do painel.
- Correção:
  - Cabeçalho: `.git-scm__toolbar` com `flex-wrap`; repo `flex: 1 1 0; min-width: 120px`; branch numa linha com reticências (`nowrap` + `overflow: hidden`); botões `flex-shrink: 0` + `margin-left: auto`. Quando não cabem, os botões descem para uma segunda linha alinhada à direita e nunca ficam sobre o texto. O caminho completo do repo vai em `data-tip` + `aria-label`.
  - Sub-abas: rótulos inteiros (`flex: 0 0 auto`); se faltar espaço, a faixa rola na horizontal com o mesmo fade de máscara das abas externas do painel. Nenhuma palavra fica cortada sem pista.
  - Linha de arquivo: `li` virou flex; as ações (`.git-scm__tree-actions`) ficam no fluxo, fora da área do nome. Em repouso ficam `display: none`, então o nome usa a largura toda. Em hover ou foco entram, e o nome encolhe com reticências respeitando-as. Saiu o overlay absoluto com gradiente.
  - Tooltip: o `title` nativo do arquivo virou `data-tip`, mostrado por um `::after` CSS com largura presa à linha (`left/right: 2px`). Ele quebra linha dentro do painel e aparece depois de 450 ms. As pastas mantêm `title`.
- Testes: `ContextualPanel.layout.test.tsx` ganhou casos novos. As abas devem ter `overflow-x: auto` e a máscara com fade. As ações do cabeçalho devem ser irmãs da área do repo, sem encolher, com wrap. A linha de arquivo deve ter `data-tip` sem `title`, e as ações fora de `.git-scm__file-main`. O helper de `DiffFileTree.test.tsx` agora lê `data-tip` (arquivos) ou `title` (pastas).
- Validação (node@22, via launchd):
  - `npx vitest run src/renderer/components/ContextualPanel.layout.test.tsx src/renderer/components/diffs src/renderer/components/GitPanelBody`: 5 arquivos, 29/29.
  - `npx vitest run src/renderer/App.test.tsx src/renderer/App.overlays.test.tsx src/renderer/lib/diff-file-tree.test.ts`: 80/80.
  - `npm run typecheck`: ok.
