- (resolvedor) Correcao:

  - `mission-snapshot.ts`: `deliveries` opcional na view; o agente leva o `model`; sem arestas gravadas, `missionTeamEdges` cria Delegação do orquestrador para cada agente e Entrega de cada um que entregou. Os pacotes usam o mecanismo existente (`isCableLive`).
  - Renderer, CSS e `missionAgentSchema` sem mudança (o contrato do snapshot é o mesmo; `model` já era opcional).
