# F-617 — Sondas Claude reabriam o modal do Keychain em loop

## F-617 | categoria: funcional | severidade: alta | status: corrigido
- Tela/fluxo: Providers/contas Claude; watcher do terminal de login; snapshots
  de cota e preparo de spawn.
- Arquivo:linha: `src/main/adapters/claude-credential.ts`,
  `src/main/adapters/native-oauth-keychain.ts`.
- Passos: 1) O macOS negar/bloquear leitura do item
  `Claude Code-credentials`; 2) abrir Providers ou iniciar login; 3) observar
  novas sondas.
- Esperado: uma negação não abre o mesmo diálogo continuamente; login novo
  fica visível assim que concluído.
- Observado: caminhos sync e async executavam `security ... -w` repetidamente.
  Cada negação virava "sem sessão" e o polling de 2 s levantava outro modal.
- Evidencia: screenshot de 21/09/2026 e leitura dos call sites de auth/cota.
- (resolvedor) Correcao: cache curto para leitura válida/ausente, backoff de 5
  min para ACL indisponível, bypass pós-sucesso que nunca ignora negação, e
  seed do cache após captura/escrita confiável. Validação:
  `npx vitest run src/main/adapters/claude-credential.keychain-cache.test.ts
  src/main/adapters/native-oauth-keychain.cache.test.ts`.
- Reaberto em 21/09: chamadas assíncronas simultâneas ainda iniciavam leituras
  separadas; uma negação também acionava `claude auth status`, fora do recuo.
  Invalidação/captura durante uma leitura pendente permitia ao resultado antigo
  sobrescrever o cache pós-login.
- (resolvedor) Complemento: leituras concorrentes compartilham o mesmo processo
  por serviço; invalidação/captura impede publicação tardia de resultados
  antigos; uma leitura pós-login espera a anterior e consulta de novo sem
  ignorar negação. Pedidos pós-login simultâneos compartilham a observação nova,
  inclusive quando aguardam a mesma leitura anterior. Negação agora propaga
  estado desconhecido e não inicia
  `claude auth status`; item ausente ainda permite essa atestação. RED:
  oito regressões falharam antes das respectivas correções. GREEN: 75 testes passaram em
  `native-oauth-keychain.cache.test.ts`, `subscription-auth.keychain-cache.test.ts`
  e `subscription-auth.test.ts`; `npm run typecheck` passou.
  O alerta de gravação relatado em outro Mac ainda depende do texto exato;
  esta validação não comprova correção do ambiente remoto nem publicação.
