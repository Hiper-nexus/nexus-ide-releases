# F-426 — sprintf-js bloqueia o audit da toolchain

## F-426 | categoria: seguranca | severidade: media | status: corrigido
- Tela/fluxo: segurança das ferramentas de build da release.
- Arquivo: `package.json`, `package-lock.json`.
- Passos: executar `npm audit --json` com npm 12.0.0 na candidata.
- Esperado: zero vulnerabilidades reportadas na toolchain.
- Observado: A toolchain trazia sprintf-js 1.1.3 por roarr/global-agent/@electron/get. A falha de precisão sem limite pode lançar RangeError em formatação controlada externamente; npm propaga o finding aos dependentes. Não há versão corrigida publicada no advisory consultado.
- Evidencia: `/tmp/nexus-206-audit-all.json`; [advisory](https://github.com/advisories/GHSA-hp3w-g68c-fv3c).
- (resolvedor) Correcao: Override restrito a @electron/get@3.1.0 para global-agent 4.1.3, preservando bootstrap CommonJS e removendo roarr/sprintf-js da árvore. Smoke real de HTTP por proxy local passou; nenhuma verificação TLS foi desabilitada. Candidata 0.76.206 ainda sem publicação.

- Validação: npm 12.0.0 audit completo com zero vulnerabilidades; typecheck exit 0 e 42 testes focados aprovados. Revisão independente do diff sem P1/P2. Suíte completa e nova candidata ainda pendentes.
