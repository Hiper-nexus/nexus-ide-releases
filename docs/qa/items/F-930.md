# F-930 — Smoke do pacote Windows reprova a licença do ONNX Runtime em checkout CRLF

## F-930 | categoria: build | severidade: alta | status: corrigido
- Tela/fluxo: `scripts/collect-windows-release.ps1` → `node scripts/smoke-packaged-app.mjs` depois do `npm run make` no Windows.
- Arquivo:linha: `.gitattributes`; a checagem é `PINNED_RUNTIME_LICENSES` em `scripts/smoke-packaged-app.mjs`.
- Passos: checkout com `core.autocrlf=true`, `npm run make`, smoke do pacote.
- Esperado: smoke passa; os textos de redistribuição no pacote são os bytes oficiais.
- Observado (05/10, 0.76.194): `packaged legal artifacts are incomplete: third_party/licenses/onnxruntime-v1.19.2-MIT.txt does not match the pinned ONNX Runtime redistribution text`.
- Causa: os dois textos `onnxruntime-v1.19.2-*.txt` estão em LF no índice, mas sem atributo o Git os grava em CRLF no Windows; o Forge empacota a cópia de trabalho e o SHA-256 fixado (dos bytes LF) deixa de bater. O runner `windows-latest` também usa `autocrlf=true`.
- (resolvedor) Correcao: `.gitattributes` fixa `third_party/licenses/onnxruntime-v1.19.2-*.txt` em `eol=lf`. Depois de refazer o checkout dos dois arquivos, os hashes locais batem com os fixados; pacote refeito e smoke repetido.
- Como foi achado: primeiro build local do Windows da 0.76.194, logo depois do F-929.
