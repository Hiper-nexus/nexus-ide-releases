# F-1069 — Fábrica de CDP não encontra abas com escopo

## F-1069 | categoria: funcional | severidade: media | status: corrigido
- Tela/fluxo: contrato Main `openCdpRelayForPane`; substrato de CDP de uma aba.
- Arquivo:linha: `src/main/browser/browser-manager.ts:3133`.
- Passos: 1) Criar uma aba por `ensureBrowser(owner, scope, paneId)`. 2) Pedir um relay para esse pane. 3) Comparar com outro checkout, identidade de escopo conflitante e aba/owner encerrados.
- Esperado: o relay resolve a aba pelo escopo exato do Main, preserva a posse do debugger e recusa entradas ausentes/estrangeiras/encerradas.
- Observado: a criação usa `browserKey(scope, paneId)`, mas a fábrica consultava `browsers.get(paneId)` sem receber escopo; a aba válida sempre devolvia `null`.
