# F-1530 — Ditado do CODE chega em português quando deveria sair em inglês

## F-1530 | categoria: funcional/voz | severidade: média | status: corrigido
- Fluxo: ditado em modo CODE no Windows; a reescrita para inglês (`polishCodePrompt`) devolvia o próprio português dentro de JSON válido e o texto seguia sem tradução.
- Correção: `polishLooksLikeEcho` detecta eco (sobreposição de palavras > 60%, texto curto e palavra única idêntica não contam) e a reescrita é recusada com `reason: 'untranslated'`; a STT de fallback é sempre tentada.
- Testes: `code-prompt-polish.test.ts`, `code-dictation.test.ts`.
- Não coberto: a gravação fantasma ("como se segurasse espaço") no Windows continua aberta.
