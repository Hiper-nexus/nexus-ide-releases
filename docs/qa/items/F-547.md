# F-547 — Smoke de Codex Windows não roda fora do GitHub Actions

## F-547 | categoria: funcional | severidade: media | status: corrigido
- Tela/fluxo: validação local do pré-requisito Codex antes da release Windows.
- Arquivo:linha: `scripts/install-windows-smoke-codex.ps1:8`.
- Passos:
  1) Rodar `./scripts/install-windows-smoke-codex.ps1` em um Windows local.
  2) Observar que `RUNNER_TEMP` e, no fim, `GITHUB_PATH` não existem fora do
     GitHub Actions.
- Esperado: o mesmo smoke de PTY deve poder validar a máquina local e o runner
  assinado, usando o diretório temporário disponível em cada ambiente.
- Observado: o script parava no primeiro `Join-Path` com argumento `Path` nulo
  antes de instalar e testar o Codex nativo.
- Evidencia: reprodução local em 2026-09-15:
  `Cannot bind argument to parameter 'Path' because it is null` na linha 8.
- (resolvedor) Correcao:
  - `scripts/install-windows-smoke-codex.ps1` agora usa `RUNNER_TEMP` no CI,
    cai para `TEMP`/`GetTempPath()` localmente e escreve em `GITHUB_PATH` apenas
    quando essa variável existe.
  - Commit `7983c375` (`fix(release): F-547 — run Windows Codex smoke locally`).
  - Validacao local: `./scripts/install-windows-smoke-codex.ps1` instalou o
    Codex fixado em diretório temporário e retornou
    `[windows-smoke] native Codex node-pty proof: codex-cli 0.145.0`.
