# F-859 — MiMo repetia uma página de IDs nativos inválidos

## F-859 | categoria: funcional | severidade: media | status: corrigido
- Tela/fluxo: telemetria de tokens MiMo por checkout.
- Arquivo:linha: `src/main/usage/mimo-worker-core.ts`, seleção paginada de mensagens.
- Passos: numa fixture privada, inserir 128 mensagens com IDs acima do limite do cursor, depois uma mensagem válida; varrer duas vezes.
- Esperado: a mensagem válida é alcançada e contabilizada uma vez.
- Observado: as linhas inválidas ocupavam LIMIT 128 antes da validação; cursor ficava em zero para sempre.
- Evidencia: RED real retornou zero eventos nas duas passagens; GREEN retorna `msg-reachable` uma vez, também com um ID BLOB anterior.
- (resolvedor) Correcao: filtrar tipo TEXT e comprimento UTF-8 de 1–256 bytes na SQL antes do LIMIT, garantindo que cada ID selecionado cabe no contrato de cursor. DB nativo segue readonly, sem alteração de schema/índice.
- Validação: Node22, lock compartilhado, maxWorkers1: scanner/parser/protocolo 3 arquivos / 16 testes passaram; tsc --noEmit passou; renderer sink audit: 0 executable DOM sinks. Só fixtures privadas foram usadas.
