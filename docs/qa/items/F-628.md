# F-628 — Nexus Redline recusado nesta versão do macOS

## F-628 | categoria: funcional | severidade: alta | status: corrigido
- Tela/fluxo: barra de menu, companheiro Nexus Redline.
- Arquivo:linha: `scripts/build-macos-menubar.mjs` (swiftc sem `-target`).
- Passos: 1) abrir o Nexus Redline instalado em `/Applications` no macOS 27.0 (build 26A428); 2) observar o alerta do sistema.
- Esperado: o companheiro abre na barra de menu.
- Observado: «Você não pode usar esta versão do aplicativo “Nexus Redline” com esta versão do macOS», com botão Atualização de Software. O binário 0.76.75 tinha `LC_BUILD_VERSION minos 27.2` e `sdk 27.0`. O Info.plist dizia 14.0, mas o Launch Services obedece o minos do Mach-O.
- (resolvedor) Correção: `swiftc` recebe `-target arm64-apple-macosx14.0`, o mesmo piso do plist. O build falha se o `minos` carimbado não for 14.0.
- Validação: `npx vitest run scripts/build-macos-menubar.test.mjs`; `node scripts/build-macos-menubar.mjs`; `vtool -show-build` mostra `minos 14.0`; o processo `NexusRedline` permanece no ar.
- Limites: um Nexus já empacotado com o binário 27.2 recoloca essa cópia em `/Applications` no próximo boot (`syncInstalledRedline`). A correção fica estável na release que embute o binário novo.
