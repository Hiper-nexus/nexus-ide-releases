# F-613 — "Enviar para o NexusIDE" no Nexus Shot não entregava os arquivos ao terminal/agente

## F-613 | categoria: funcional | severidade: média | status: corrigido

- Tela/fluxo: Nexus Shot (app de captura de tela/gravação) → "Enviar para o NexusIDE"
  com um terminal/agente ativo (ex.: Antigravity, Claude, Codex, Grok).
- Arquivo:linha: `src/renderer/state/shot-ingest.ts`,
  `src/renderer/state/shot-ingest.test.ts`.
- Passos: 1) Capturar uma imagem ou gravação no Nexus Shot; 2) Clicar em "Enviar para o NexusIDE";
  3) O NexusIDE vem para o primeiro plano e exibe o toast ("Nexus Shot: N arquivos recebidos");
  4) Olhar para o terminal/agente ativo.
- Esperado: O arquivo capturado é entregue ao pane/agente ativo (caminho estagiado em
  `.nexus/attachments/mission-context/` ou caminho validado é inserido no prompt do terminal),
  para que o operador possa submeter o prompt ao agente imediatamente com o anexo.
- Observado: O IDE apenas exibia o toast com ações "Abrir" / "Abrir pasta", mas nada chegava
  ao terminal ou ao agente. O operador precisava localizar manualmente o arquivo no Finder e
  arrastar para o terminal.
- Causa: No F-577, foi construída apenas a superfície inicial com toast de notificação;
  a anexação e injeção do shot no pane ativo havia sido deixada como passo futuro ("anexar o shot
  como contexto no compose de um pane é próximo passo de produto").
- Correção: `src/renderer/state/shot-ingest.ts` agora resolve o pane alvo (`resolveShotTargetPaneId`:
  pane focado com sessão viva, ou primeiro `cli-agent` vivo, ou qualquer terminal vivo), seleciona
  os arquivos prioritários (`selectShotFilesToInject`: em gravações com muitos frames, prioriza
  contact-sheet e vídeo para não floodar o buffer), estagia via `importDroppedUri` em
  `.nexus/attachments/mission-context/` (com fallback ao path real validado) e escreve o caminho
  formatado no PTY do pane com trailing space (`writeToPane`), atualizando o toast para indicar que
  foi inserido no terminal.
- Validação: `npx vitest run src/renderer/state/shot-ingest.test.ts` (11 testes),
  `npm run typecheck`, `npm run security:renderer-sinks` (0 sinks executáveis).
