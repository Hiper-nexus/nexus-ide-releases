# F-411 — Electron 43.0.0 com quatro alertas altos de segurança bloqueava a release

## F-411 | categoria: seguranca | severidade: alta | status: corrigido
- Tela/fluxo: runtime do app (Electron) e gate `npm run release:security`.
- Arquivo:linha: `package.json` (`"electron": "^43.0.0"`, lockfile em 43.0.0); `scripts/install-electron.mjs:9` (`EXPECTED_ELECTRON_VERSION = '43.0.0'`).
- Passos: 1) Com o Node da release (22.23.2), rodar `npm run release:security` no HEAD da 0.76.139. 2) Rodar `npm audit`.
- Esperado: audit de produção e do toolchain em 0; o app empacotado sem alerta conhecido.
- Observado (29/09, depois da publicação da 0.76.138): "release bloqueada: build toolchain tem 1 vulnerabilidade". `npm audit` aponta `electron` (alto) com quatro alertas: GHSA-gr2m-v5gq-v685 (janela aberta de documento em sandbox não herda o sandbox), GHSA-j84w-jfhq-vhvj (handlers file/HTTP permitem leitura cross-origin sem corsEnabled), GHSA-9qh4-3jw8-366w (`<webview>` liga Node em Web Workers apesar do embedder) — corrigidos em 43.4.1 — e GHSA-qmv3-fv6v-rmhq (cache de código do preload em sandbox envenenável por renderer comprometido), corrigido em 43.5.0. A 0.76.138 já publicada roda o mesmo Electron 43.0.0.
- Evidencia: saída do `release:security` e do `npm audit --json` de 29/09; `npm view electron time` (43.7.4 publicado em 2026-09-22, sete dias antes).
- Relacionado: F-199, F-200, F-214 (release 0.76.139).
- (resolvedor) Correcao: upgrade do Electron 43.0.0 → 43.7.4 (publicado 2026-09-22, cobre os quatro alertas: três corrigidos em 43.4.1 e o GHSA-qmv3-fv6v-rmhq em 43.5.0). `package.json` `"electron": "^43.7.4"` + lockfile apenas no registro `node_modules/electron` (versão/resolved/integrity; `npm install --save-dev electron@43.7.4` com npm 12.1.0); `EXPECTED_ELECTRON_VERSION = '43.7.4'` em `scripts/install-electron.mjs` (o pino de supply-chain acompanha o upgrade). Binário baixado conferido: `require('electron/package.json').version` e `CFBundleShortVersionString` do `Electron.app` = 43.7.4. `npm audit` e `npm audit --omit=dev` → 0 vulnerabilidades. Nenhum outro controle de segurança, `.npmrc` ou ajuste de audit tocado. Verificação: suíte completa `npx vitest run` 1604 arquivos / 17 417 testes (15 skipped, 0 falhas), `npm run typecheck` 0, `npm run security:renderer-sinks` 0 sinks executáveis, `scripts/install-electron.test.mjs` 2/2 via vitest.
