# F-1244 — Prova Linux do sandbox (owned-linux-command) falhava sempre: o teste punha o sandbox dentro do checkout

## F-1244 | categoria: funcional | severidade: media | status: corrigido
- Tela/fluxo: passo "Prove Linux command namespace lifetime" do `ci.yml`, que roda `src/main/orch/owned-linux-command.test.ts` com `NEXUS_LINUX_OWNED_COMMAND_TEST=1`.
- Arquivo:linha (antes): `src/main/orch/owned-linux-command.test.ts:152` (`path.join(root, 'sandbox')`) contra `src/main/runtime/process-sandbox.ts:553-554`.
- Observado: no CI de Linux local (container `node:22.23.2-bookworm`, bubblewrap 0.8.0), o teste falha com `sandbox private runtime must be disjoint from the project checkout`. A fixture criava o runtime privado DENTRO do checkout, e o produto recusa exatamente isso. Como o CI do GitHub está sem orçamento de Actions, ninguém via.
- (resolvedor) Correcao: o sandbox nasce num `mkdtemp` próprio, fora do checkout, e é limpo no fim. O produto não mudou.
- Validacao: CI Linux local fiel ao runner, `owned-linux-command`: 20/20.
