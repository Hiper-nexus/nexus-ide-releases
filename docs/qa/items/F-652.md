# F-652 — Release macOS morre no codesign quando o timestamp da Apple trava por IPv6

## F-652 | categoria: funcional | severidade: alta | status: corrigido
- Tela/fluxo: `npm run release:mac` → etapa build (`make:release`) → electron-packager/osx-sign → `codesign --timestamp=http://timestamp.apple.com/ts01`. Faixa F-5XX (build) esgotada; segue a numeração corrente.
- Arquivo:linha: `build/mac-signing.ts` (`APPLE_TIMESTAMP_AUTHORITY_URL`, usado em `optionsForFile`), `scripts/release-mac-detached.mjs` (ambiente do job do launchd).
- Passos: 1) Rede com rota IPv6 preferida e quebrada até timestamp.apple.com. 2) `npm run release:mac`.
- Esperado: a assinatura recebe o carimbo seguro da Apple e a release segue para a notarização.
- Observado (26/09): a 0.76.103 parou em "Finalizing package" às 12:02 e nunca foi publicada (o GitHub seguia na 0.76.101, então o app instalado dizia estar em dia); a 0.76.104 falhou em `sshcrypto.node: A timestamp was expected but was not found`. Requisição RFC 3161 à mesma autoridade: IPv4 responde 200 em 0,3 s; IPv6 conecta, envia e nunca responde (timeout de 25 s). `codesign --timestamp=http://17.32.213.161/ts01` assina com carimbo da Apple.
- Evidencia: `curl -4`/`curl -6` com `ts-req.tsq`; `codesign -dvv` com `Timestamp=26 Sep 2026 at 15:06:07` e `Authority=Developer ID Application`. O perfil `nexus-notary` está válido (`notarytool history`: 0.76.101 Accepted).
- (resolvedor) Correcao: `NEXUS_MAC_TIMESTAMP_URL` troca a autoridade só na execução que a define (`macTimestampAuthority`); só URL http/https é aceita, então não dá para desligar o carimbo por ela. O disparador repassa a variável ao job do launchd, que não herda o ambiente de quem chamou, e o `make-release` a inclui na lista de variáveis que chegam ao Electron Forge (o resto do ambiente continua filtrado). Sem a variável, nada muda.
- Uso: `NEXUS_MAC_TIMESTAMP_URL=http://<IPv4 de timestamp.apple.com>/ts01 npm run release:mac` quando o IPv6 falhar.
- Validação: `build/mac-signing.test.ts` e `scripts/release-mac-detached.test.mjs` (51 testes).
