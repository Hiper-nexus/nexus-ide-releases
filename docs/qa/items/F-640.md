# F-640 — No Windows a cota das contas Claude gerenciadas nunca lê pela CLI (e ninguém renova o token)

## F-640 | categoria: funcional | severidade: alta | status: corrigido
- Tela/fluxo: cota/Redline das contas Claude de assinatura (Configurações › Contas de IA) no Windows; renovação de fundo do escopo gerenciado.
- Arquivo:linha: `src/main/quota/claude-oauth-usage.ts:415` (`locateClaudeBinary` só olhava candidatos POSIX: `~/.local/bin/claude`, nvm, Homebrew).
- Passos: 1) Windows com Claude Code instalado pelo npm (`claude.cmd` no PATH) ou pelo instalador nativo (`claude.exe`). 2) Duas contas Claude gerenciadas. 3) Deixar o Nexus aberto sem pane dessas contas por mais de 8 h.
- Esperado: a sonda `claude --print /usage` roda no escopo de cada conta; a CLI renova o token dela sob o próprio lock, e a cota aparece.
- Observado: `cli-missing` sempre — nenhum candidato POSIX existe no Windows. A sonda nunca rodou: a pasta `quota` da conta nem existia. Sem esse run ninguém renova o escopo gerenciado; o access token vence e o próximo pane é recusado (F-639). Mesmo com o caminho certo, `spawn` sem shell não executa `.cmd` (Node recusa desde o CVE-2024-27980).
- Evidencia: 24/09, este PC: `~/.nexus/managed-accounts/claude/<acct>/auth/.credentials.json` das duas contas com `expiresAt` vencido havia ~19 h e sem `quota/` ao lado; `where claude` → `…\node-v22…\claude.cmd`, que lança `node_modules\@anthropic-ai\claude-code\bin\claude.exe`.
- (resolvedor) Correcao: no win32 o CLI vem do PATH (`resolveCliBinary`, o mesmo resolvedor dos panes) e o shim do npm vira o `claude.exe` que ele lança (`windowsClaudeExecutable`, sobre `claudeCapabilityProbePath`, que só aceita alvo dentro da pasta do shim — o mesmo arquivo que a checagem de marcador lê). Shim que não resolve para um `.exe` continua `cli-missing`. O env do run gerenciado virou `managedClaudeCliEnv`, compartilhado com o spawn (F-639). Testes: `claude-oauth-usage.test.ts` — Windows sem candidato POSIX acha o CLI no PATH (falha no código antigo) e o shim resolve para o exe.
