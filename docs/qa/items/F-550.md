# F-550 — Teste do smoke empacotado não é portável para Windows

## F-550 | categoria: build | severidade: media | status: corrigido
- Tela/fluxo: validação local do pacote antes de uma release Windows.
- Arquivo:linha: `scripts/smoke-packaged-app.test.mjs:108`,
  `scripts/smoke-packaged-app.test.mjs:197`,
  `scripts/smoke-packaged-app.test.mjs:860`.
- Passos:
  1) Executar `npx vitest run scripts/smoke-packaged-app.test.mjs` no Windows.
- Esperado: os testes estruturais dos três alvos passam no host Windows;
  simulações de macOS/Linux não dependem do utilitário POSIX `ps`.
- Observado: seis testes falham porque esperam literalmente caminhos `/tmp`
  e porque uma fixture simulada de macOS usa o inventário real de processos
  POSIX no host Windows.
- Evidencia: saída de Vitest em 2026-09-16: 57 testes, 6 falhas, incluindo
  `spawnSync ps ENOENT` e caminhos recebidos `C:\\tmp\\...`.
- (resolvedor) Correcao:
  - As expectativas de caminho agora usam `path.resolve`/`path.join`, tal como
    o harness, em vez de pressupor que a máquina que roda a suíte é POSIX.
  - A fixture que simula macOS injeta o inventário de árvore de processos;
    ela testa o harness sem pedir o binário `ps` inexistente no host Windows.
  - Commit `b50ec422` (`test(release): F-550 — make packaged smoke portable on Windows`).
  - Validação: `npx vitest run scripts/smoke-packaged-app.test.mjs` passou
    com 57 testes no Windows.
