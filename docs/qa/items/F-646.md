# F-646 — No Windows o pane com login nativo renovava numa cópia do `.credentials.json`

## F-646 | categoria: funcional | severidade: alta | status: corrigido
- Tela/fluxo: pane Claude direto (não gated) que usa o login nativo — pane sem conta e, depois do F-645, a conta que é o login nativo — no Windows e no Linux.
- Arquivo:linha: `src/main/orch/hooks-gen.ts:671` (overlay recebia `~/.claude/.credentials.json` por `linkFile`: hardlink no Windows, cópia no fallback), `src/main/orch/overlay-auth-syncback.ts:77` (o fechamento copia o arquivo do overlay de volta ao perfil real).
- Passos: 1) Pane Claude com login nativo aberto por mais de 8 h. 2) A CLI do pane renova o token. 3) Usar o `claude` fora do Nexus.
- Esperado: um só arquivo de credencial — renovar no pane atualiza o perfil real.
- Observado: a CLI grava a credencial por temporário + rename (`hee`/`In` no binário 2.1.281; só grava no próprio arquivo quando o temporário é recusado). O rename troca o hardlink do overlay por um arquivo novo: o pane segue com o token novo, o `~/.claude/.credentials.json` real fica com o refresh token já consumido, e o Claude de fora cai na renovação seguinte. O sync-back do fechamento só corrigia no fim — e, com a credencial gravada no real, devolveria um token velho.
- Evidencia: strings do `claude.exe` 2.1.281 (`renameFn`, `inPlaceOnTempCreateRefused`). Teste físico em 24/09: overlay sem credencial → `claude auth status` `loggedIn: false`; com `CLAUDE_SECURESTORAGE_CONFIG_DIR=~/.claude` real → `loggedIn: true` (`claude.ai`), conversas no overlay e o arquivo real intocado.
- (resolvedor) Correcao: fora do macOS, pane Claude primeiro-parte, não gated e sem escopo gerenciado recebe `CLAUDE_SECURESTORAGE_CONFIG_DIR=<~/.claude real>` e o overlay não recebe cópia nem link do `.credentials.json` (`nativeCredentialsInPlace`) — a CLI lê e renova o arquivo real, e o sync-back não tem o que devolver. Conversas continuam no overlay. macOS inalterado (o segredo vive no keychain, já ligado ao overlay). Gated e terceiros continuam autenticando por env. Testes: `hooks-gen.claude-auth.test.ts` › "F-646" (sem cópia no overlay; o fechamento não devolve token velho — falha no código antigo), `mcp-server-governed-profile.test.ts` (env do Claude direto fora do Mac).
