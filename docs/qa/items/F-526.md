# F-526 — Smoke declara prova física quando inventário Windows é indisponível

## F-526 | categoria: seguranca | severidade: media | status: corrigido
- Tela/fluxo: encerramento do smoke empacotado Windows.
- Arquivo:linha: `src/main/main.ts`.
- Passos: 1) encerrar a sessão PTY do smoke no Windows; 2) observar falha
  fail-closed do inventário de descendentes; 3) observar a mensagem final.
- Esperado: o log distingue teardown concluído de inventário físico comprovado.
- Observado: após registrar `termination proof failed`, o main imprimia
  `shutdown-complete: physical PTY inventory proven` incondicionalmente.
- Evidencia: Actions run 11 contém as duas mensagens contraditórias na mesma
  sessão.
- (resolvedor) Correcao: o marcador `shutdown-complete` só é emitido quando o
  resultado contém inventário físico exato; os demais casos emitem
  `shutdown-unproven`. O encerramento sem veto e o registro de incidente não
  mudaram. A implementação de inventário Windows permanece fora deste fix e
  exige desenho revisado com Job Object/handles nativos para fechar PID reuse e
  descendentes reparentados. 84 testes relacionados, typecheck e sinks passaram.
