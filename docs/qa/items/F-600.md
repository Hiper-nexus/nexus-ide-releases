# F-600 — Painel Git corta nome e caminho dos arquivos (ilegível)

## F-600 | categoria: usabilidade | severidade: media | status: corrigido
- Tela/fluxo: ContextualPanel → Git → Alterações (lista Changes/Staged).
- Arquivo:linha: `src/renderer/components/GitPanelBody.tsx` (`FileRow`);
  `src/renderer/styles/git-scm.css` (`.git-scm__file-main`, `.git-scm__name`,
  `.git-scm__path`, `.git-scm__file-actions`).
- Passos: 1) Abrir o painel Git com o painel lateral estreito. 2) Ter
  alterações em diretórios profundos. 3) Tentar ler nome/caminho.
- Esperado: nome do arquivo sempre legível; diretório cede espaço primeiro;
  ações de stage/discard não roubam largura do texto.
- Observado: linha em 2 linhas com grid `16px 1fr`; os botões ↺/+ (56 px)
  comprimiam o texto e tanto o nome ("AGENT…", "model-c…") quanto o caminho
  ("src/main/m…") saíam truncados pelo início útil — impossível ler.
- Evidencia: print do operador em `.nexus/attachments/mission-context/`
  (2026-09-19T23-11-51) — 37 changes, todos os nomes cortados.
- (resolvedor) Correcao: linha única estilo VS Code — grid
  `14px minmax(0, max-content) minmax(0, 1fr)` (nome tem prioridade, diretório
  encolhe primeiro e trunca pela ESQUERDA via `direction: rtl`, mantendo o
  final do caminho visível); path mostra só o dirname (rename fica no
  tooltip); ações ↺/+ viram overlay absoluto revelado no hover/focus-within;
  cabeçalho da seção com `flex-wrap` e links `nowrap` ("Descartar tudo" não
  quebra mais no meio).
