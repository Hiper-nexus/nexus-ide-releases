# F-1555 — Texto dos botões Git desaparece ao pressionar no tema roxo

## F-1555 | categoria: visual | severidade: media | status: corrigido
- Tela/fluxo: Git → Alterações → Mesa limpa; Puxar, Enviar, Ver histórico, Trocar branch. Complementa F-1554 (poll já corrigido).
- Arquivo:linha: `src/renderer/styles/product-wave.css:315`, `src/renderer/styles/product-wave.css:486`.
- Passos: usar tema Dracula, abrir Git com commits ahead/behind, manter o mouse pressionado sobre Puxar ou Enviar.
- Esperado: texto legível em repouso, hover, active, focus-visible e aria-pressed, contraste mínimo 4,5:1; estados sem interpolação de tinta/fundo.
- Observado: hover genérico aplicava `--accent` ao texto dos primários, que já tinham fundo `--accent`: contraste 1:1. Branco sobre roxo em repouso também falhava (2,41:1). O filtro brightness não recuperava contraste.
- Evidencia: `docs/qa/evidence/F-1555/dracula-pressed-before.png` (560×980 completo; mouse realmente pressionado, `:active` comprovado). `contrast-before.json`: 72 falhas em 140 combinações de botão/tema/estado. Nos secundários o hover também falhava em temas claro e Solarized.
- (resolvedor) Correcao: primitivo compartilhado `.product-pane__btn--primary` passa a consumir `--btn-primary`, `--btn-primary-ink`, `--btn-primary-hover` (DESIGN.md §2). Secundários conservam `--text`. Os estados hover/active/focus-visible/aria-pressed mantêm pares legíveis; filtro removido e transição explicitamente desligada. Corrigido no primitivo para cobrir seus demais consumidores, sem mudar handlers nem fluxo Git. Commit identificado por `git log --grep=F-1555`.
- Prova: `node --import tsx scripts/check-git-button-contrast.ts`: 140/140 em Chromium real, mínimo geral 4,58:1. Reutiliza `scripts/mobile-visual/cdp.ts`, renderiza GitPanelBody e global.css reais, aplica as 7 paletas por applyUiTheme, força pseudoclasses via CDP e mede computed style/contraste com helpers existentes. No Dracula: primários 18,85:1 em repouso, 19,67:1 nos demais estados; secundários 10,74:1 em todos. Sem filtro nem transição nos 140 casos. Screenshot posterior completa em `dracula-pressed-after.png`, inspecionada visualmente, com mouse realmente pressionado; nenhum recorte. Status Git é simulado no harness, sem preload/IPC; comandos Git não são executados.
- Validacao: suíte focada antes/depois: `npx vitest run src/renderer/components/GitPanelBody.test.tsx src/renderer/components/GitPanelBody.diff.test.tsx src/renderer/state/git-scm-store.test.ts` (29/29). `npm run typecheck`, `npm run security:renderer-sinks` e `git diff --check`.
- Limite: prova no componente real em Chromium isolado; não executado no app Electron empacotado. Capturas e JSONs foram gerados pelo check reproduzível; `--before` é somente o sufixo de saída para registrar o baseline, não restaura CSS antigo.
