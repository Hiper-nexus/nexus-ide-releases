# F-534 — Quebra do empacotamento de DMG macOS por rebuild indevido de macos-alias no runtime do Electron

## F-534 | categoria: build | severidade: alta | status: corrigido
- Tela/fluxo: Packaging do release macOS (`npm run make:release` / `electron-forge make`)
- Arquivo:linha: `forge.config.ts:456`
- Passos:
  1) Executar `npm run make:release` em ambiente limpo de release.
  2) O Electron Forge empacota a aplicação e executa o passo de rebuild de módulos nativos.
  3) O Forge inicia a geração dos distribuíveis (`MakerDMG`).
- Esperado:
  - O `MakerDMG` (que executa no ambiente Node.js do host, ABI 127) consegue carregar o módulo nativo `macos-alias/build/Release/volume.node` e gerar o `.dmg`.
- Observado:
  - O Forge falha em `Making a dmg distributable for darwin/arm64` com o erro:
    `The module '.../macos-alias/build/Release/volume.node' was compiled against a different Node.js version using NODE_MODULE_VERSION 148. This version of Node.js requires NODE_MODULE_VERSION 127.`
  - Causa raiz: `forge.config.ts` configurava `rebuildConfig: { mode: 'sequential' }` sem especificar `onlyModules`. Com isso, o `@electron/rebuild` interno do Forge varria todas as dependências do projeto e recompilava ferramentas de build do Node (`macos-alias`, `ds-store`, `fs-xattr`) para o Electron (NODE_MODULE_VERSION 148).
- Evidencia:
  - `rebuildConfig` no `forge.config.ts` atualizado para incluir `onlyModules: ['@lydell/node-pty', 'better-sqlite3', 'onnxruntime-node']`.
  - Módulos nativos exclusivos de tooling do Node como `macos-alias` permanecem intactos com a ABI do Node 22 (`127`).
  - Testes validados em `forge.config.test.ts` (21 passed) e `npm run typecheck`.
- (resolvedor) Correcao:
  - `forge.config.ts`.
