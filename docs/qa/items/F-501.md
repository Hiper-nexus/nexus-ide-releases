# F-501 — Vitest coletava teste arquivado como evidência

## F-501 | categoria: funcional | severidade: media | status: corrigido
- Tela/fluxo: Suíte completa antes da release 0.76.2.
- Arquivo:linha: `vitest.config.ts:20`.
- Passos: Executar npm test com o exemplo generated-library preservado em docs/qa/evidence.
- Esperado: O Vitest coleta as suítes do produto; exemplos arquivados continuam evidências, executáveis por seu runner próprio.
- Observado: sum.test.mjs importa node:test e é tratado pelo Vitest como arquivo sem suíte, causando falha de coleta.
- Evidencia: A suíte executou 12.297 testes de produto com sucesso, mas falhou no arquivo arquivado. O mesmo exemplo passou seis testes com node --test.
- Correcao: Excluída somente a árvore de evidências arquivadas da coleta do Vitest, como já ocorre com exemplos de skills. Nenhuma suíte do produto foi excluída.
