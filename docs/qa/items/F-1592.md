# F-1592 — Música de fundo para vídeo: `nexus_music_generate`

## F-1592 | categoria: funcional | severidade: baixa | status: corrigido

- Tela/fluxo: agente montando vídeo de apresentação (estúdio de vídeo, passo 3 de `docs/analysis/2026-10-19-estudio-de-video.md` §5.3).
- Arquivo:linha (antes): `src/main/orch/tools-media.ts` (só imagem, vídeo e TTS); nenhum caminho para `POST /v1/music`.
- Passos: 1) Pedir "vídeo de 45 s com música instrumental". 2) O agente procura uma ferramenta de música.
- Esperado: trilha instrumental com licença clara para vídeo de produto, paga com a chave que o usuário já tem, custo antes de pagar.
- Observado: nenhuma ferramenta; o agente baixaria faixa da internet ou pediria outra conta (Suno/Udio não têm API de uso comercial, estudo §2.4).
- (resolvedor) Correcao:
  - `src/main/media/music-generation.ts`: `POST /v1/music?output_format=mp3_44100_128` com `prompt`, `music_length_ms` (3.000 a 600.000), `model_id` (padrão `music_v2_5`, o mais novo; aceitos `music_v2_5`, `music_v2`, `music_v1`), `force_instrumental` (padrão verdadeiro) e `sign_with_c2pa: true` (a ElevenLabs assina o MP3 com manifesto C2PA, AI Act art. 50(2)). Grava o mp3 e `<nome>.provenance.json` (provedor, modelo, duração, instrumental, `digitalSourceType` `trainedAlgorithmicMedia`, `songId` do cabeçalho quando vem), ambos pela guarda de caminho do workspace.
  - Custo de lista US$ 0,15/min (elevenlabs.io/pricing/api, 19/10); `dryRun` devolve custo e licença sem rede.
  - Prompt com artista: a API devolve `detail.status = "bad_prompt"` com `detail.data.prompt_suggestion`; a ferramenta devolve `ok: false`, a frase do que fazer e `promptSuggestion` para o agente mostrar ao operador antes de usar. Nada é gravado.
  - O resultado leva `license` com o resumo dos termos da Eleven Music (plano pago para uso comercial, faixa por tamanho de empresa, sem nome de artista, sem biblioteca para terceiros, link dos termos).
  - Ferramenta `nexus_music_generate` em `src/main/orch/tools-voice.ts`; `music_generate` em `EXECUTION_EFFECT_TOOLS`; confirmação descreve duração, tipo e destino sem o prompt (`jarvis/guardrails.ts`); mãos-livres "mantém o modal". Geração paga entra no registro de uso de mídia.
  - Fora de `media-generation.ts` de propósito (o estudo listava esse arquivo): ele está sendo refeito em `feat/model-compare-media`, e a música só precisa da chave.
- Evidencia/validacao: `src/main/media/music-generation.test.ts` (7: corpo exato do pedido com C2PA e instrumental, mp3 + proveniência, `bad_prompt` com sugestão e nada gravado, faixas e caminhos recusados antes da rede, sem chave sem rede); `tools-voice.test.ts` (efeito, repasse, sem registro quando recusada); `guardrails.test.ts`; `guardrails-hands-free.test.ts` (contrato com o registro real). `npm run typecheck` sem erro.
- Limite: NÃO medido com a API real (sem acesso à chave nesta sessão): se a conta aceita `music_v2_5` com `force_instrumental` e `sign_with_c2pa`, e o nome do cabeçalho do id da faixa. `WITH_MUSIC=1 npx tsx scripts/elevenlabs-live-check.mts` testa os três com 5 s (~US$ 0,0125). Se o `music_v2_5` não estiver disponível na conta, o erro da API aparece como está e o agente pode pedir `model: "music_v2"`.
