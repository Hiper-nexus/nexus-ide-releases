# F-020 — Cota vencida reaparece como recém-consultada

## F-020 | categoria: funcional | severidade: media | status: corrigido
- Fluxo: cache de Uso e cotas.
- Arquivo: `src/main/quota/quota-service.ts`.
- Esperado: preservar a hora da observação durante o TTL; descartar percentuais vencidos se a nova consulta falhar.
- Observado: refresh normal que falhava mantinha o cache vencido, enquanto `entry.updatedAt` passava a indicar agora.
- Evidência: RED com API simulada respondendo sucesso, seguido de erro após 60 segundos; segundo RED para timestamp dentro do TTL.
- Correção: falha remove o cache; sem nova prova os valores ficam `null`. Durante o TTL, `entry.updatedAt` mantém o instante da observação. `snapshot.updatedAt` representa a consulta da frota.
- Validação: 144 testes de quota/native auth isolados; typecheck e renderer sinks.
