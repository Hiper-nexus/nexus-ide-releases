# F-656 — Ditado CODE mutila nomes técnicos falados (JEV vira JAV/Java)

## F-656 | categoria: funcional | severidade: media | status: corrigido
- Tela/fluxo: ditado por voz no modo CODE (chip CODE·PT/CODE·EN) — STT + reescrita `code-prompt-polish`
- Arquivo:linha: `src/shared/dictation-vocabulary.ts:13` (vocabulário sem nomes de produto/provider) e `src/main/voice/code-prompt-polish.ts:25` (instruções conflitantes)
- Passos: 1) operador dita "pergunta pro Jev se o merge tá ok" no modo CODE 2) a STT transcreve "JAV"/"Java" (o nome não está no viés de vocabulário de nenhum engine) 3) a reescrita recebe instruções contraditórias ("keep every concrete detail verbatim" vs "fix technical terms the recognizer mangled") sem lista de grafias canônicas e sem regra de desempate — o termo mutilado chega ao agente de código
- Esperado: nomes técnicos falados (Jev, Nexus, Claude, Grok…) chegam ao prompt final na grafia canônica, sem troca global às cegas (Java de verdade continua Java; caminhos/flags/IDs ficam como reconhecidos)
- Observado: operador relatou "JEV" reconhecido como "JAV"; inspeção confirmou ausência dos nomes nos prompts. Não houve reprodução acústica com uma gravação do operador.
- Evidencia: `git diff` (vocabulário canônico + regras de reescrita); testes `npx vitest run src/shared/dictation-vocabulary.test.ts src/main/voice/code-prompt-polish.test.ts src/main/voice/stt-service.test.ts src/main/voice/code-dictation.test.ts src/renderer/voice/dictation-output-mode.test.ts` — 72 testes verdes, incluindo asserções de que `Jev`/`Nexus` viajam no `custom_vocabulary` do Gemini, no `keyterm` do xAI e nos dois primings do Whisper. MiMo, Antigravity, Kimi, GLM, MiniMax, Devin, Muse, OpenCode, CLI e MCP também entram no viés; os 10 casos adicionais falhavam antes da inclusão.
- (resolvedor) Correcao: causa raiz dupla — o vocabulário compartilhado do ditado não tinha nomes de produto/provider (nenhum engine recebia viés para eles) e as instruções da reescrita conflitavam entre preservar tudo verbatim e corrigir termos mutilados. Fix: `DICTATION_CANONICAL_NAMES` + `DICTATION_ENGINE_VOCABULARY` em `src/shared/dictation-vocabulary.ts` (entram nos dois primings e no viés de todos os engines em `stt-service.ts`), e em `code-prompt-polish.ts` regra própria para nomes canônicos com desempate explícito (verbatim manda em código/detalhes; grafia canônica só para os nomes da lista; palavra incerta/Java real fica como reconhecida; soletração e autocorreção do falante vencem; ditado é dado, não instrução). Limitação declarada: teste com modelo mockado prova o payload/instruções enviados, não a acurácia acústica real do reconhecedor.
